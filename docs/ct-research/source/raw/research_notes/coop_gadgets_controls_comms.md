## PART B - Equipment in co-op

### B1. General rules (how co-op kit differs from solo)
- Most solo controls and gadgets carry over, with exceptions [SINGLE SOURCE - PRIMA]:
  - No whistle: the whistle button becomes the Co-op Action button [VERIFIED - PRIMA, XBM controller diagram, FW controls page].
  - EEV cannot be used, so no remote hacking from range [SINGLE SOURCE - PRIMA]. CONFLICT: the XBM co-op controller diagram still labels a button "EEV" [XBM]. Treat "no EEV in co-op" as [UNCERTAIN] until checked in-game.
  - The pistol's OCP is changed into a hold-to-jam device (see B3) [VERIFIED].
- No player-chosen loadout screen is described for co-op in either manual; PRIMA prints a fixed "Agent 1's gear / Agent 2's gear" box per Xbox/PC mission and a single shared "Agent's gear" box per PS2/GC mission [SINGLE SOURCE - PRIMA]. (Solo mode has Recommended/Stealth/Assault-style loadout choice per PS2M; nothing equivalent is documented for co-op.) [UNCERTAIN - absence of evidence]
- Xbox/PC loadouts are ASYMMETRIC: Agent One carries the launcher payloads (sticky cameras in quantity, sticky shockers, ring airfoil rounds); Agent Two carries hand grenades (flash, smoke, frag) [VERIFIED - RUW tables + PRIMA gear boxes for Chemical Bunker and Train Station agree].
- PS2/GC loadouts are SYMMETRIC: both agents get identical kit per sub-level [VERIFIED - FW PS2/GC sub-level pages + PRIMA single "Agent's gear" box].
- Shareable items: anything marked with a dot in the inventory can be handed over via "Share Equipment" (Interaction menu, both agents near each other) [VERIFIED - XBM, PS2M, PRIMA].
- Elite mode (Xbox/PC, unlocked after Story): XBM says no firearm ammo but knife available for kills; PRIMA says restricted to non-lethal weapons; RUW Elite tables show 0 rifle/pistol ammo plus a reshuffled gadget set (e.g. gas grenades instead of frags) [VERIFIED that Elite = 0 firearm ammo (XBM + RUW); UNCERTAIN on knife-vs-nonlethal wording].

### B4. How levels are built around equipment (design notes from the sources)
- Jammer gates: camera or laser grid that one agent cannot pass alone because the jam only lasts while the other agent holds it -> forced alternation (Training, Panama camera + laser grid, PS2/GC everywhere) [VERIFIED - PRIMA + IGNW + FW].
- Turret gates: jam + flank-and-switch-off (Seoul both builds, Train Station) [VERIFIED].
- Split-role kits: Agent One is the precision non-lethal shooter (shocker, airfoil), Agent Two the area-effect thrower (grenades) on Xbox/PC [VERIFIED].
- Dual locks: two retinal scanners, two bomb wires, two switches, two code locks, two Cryotank stations - all require two bodies at once [VERIFIED - PRIMA + XBM].

## PART C - Controls and interface

### C1. Co-op Action button per platform
| Platform | Co-op Action (free moves: Boost, Tomoe Nage, Human Ladder) | Contextual moves / heal / share / sync | Source |
|---|---|---|---|
| Xbox | Black button (replaces whistle) | A (Interact) via Interaction menu | [VERIFIED - XBM diagram + text, FW controls] |
| PS2 | L2 (replaces whistle) | X (Interact) | [VERIFIED - PS2M, FW controls] |
| GameCube | Z + D-pad Left (Z is a modifier; same combo whistles in solo) | A (Interact) | [SINGLE SOURCE - FW controls page] |
| PC | F, also Page Down (defaults) | Space / Enter (Interact) | [SINGLE SOURCE - FW controls page] |

- Xbox co-op default diagram (XBM p.20): left trigger KO attack / fire secondary; right trigger lethal attack / fire primary; Y jump; X equip item; B crouch; A interact; Black co-op action; White quick inventory; Back OPSAT menu; Start pause; D-pad night/thermal/sticky camera (and EMF); right stick camera, its click EEV [SINGLE SOURCE - XBM].
- Rope controls: rope holder moves partner with the triggers (Xbox L/R triggers; PS2 L1/R1); rappeller climbs with left stick. Hangover: suspended agent's inverse crouch on Xbox left trigger / PS2 L1 [VERIFIED - XBM, PS2M, PRIMA].
- Tomoe Nage aim: initiator steers a target reticule after pressing Co-op Action (red = invalid) [VERIFIED].
- PC "Say (Coop)": T and End keys [SINGLE SOURCE - FW controls]; presumably opens the text chat box that XBM lists on the HUD ("Chat box: used to communicate with Co-op partner in text format") [UNCERTAIN link between the two].
- PC: F5 quick save / F8 quick load exist in the default map [SINGLE SOURCE - FW controls; not confirmed for co-op].
- Versus (for comparison, Xbox): White = start/finish a co-op move; A = heal partner, give/accept gadget [SINGLE SOURCE - XBM p.31].

### C2. "Say" / quick-chat / automatic voice lines (no headset)
- "Alternative Voice Communication" switches on automatically for an agent without a headset; it only works in specific situations [VERIFIED - XBM p.26, PRIMA]:
  - When an agent initiates a co-op move or interaction, a recorded voice message tells the partner he is waiting; another plays on completion [VERIFIED - XBM, PRIMA].
  - When an agent's health hits zero a message tells the partner he needs help [SINGLE SOURCE - PRIMA].
  - During Hangover (suspended agent): click-and-hold left stick + up/down sends "Up"/"Down"; release sends "Stop" [VERIFIED - XBM p.27, PRIMA].
  - During Dual Rappelling (rappeller): click-and-hold left stick + left/right sends "Left"/"Right"; release = "Stop" [VERIFIED - XBM, PRIMA].
  - Crane: pick the "Crane Communication" interaction at the top of the HUD, then click-hold left stick up/down/left/right = "Back"/"Forward"/"Left"/"Right", + left trigger = "Lower", + right trigger = "Raise", release = "Stop" [SINGLE SOURCE - XBM p.27].
- Synchronized puzzle actions without a headset: first player selects the action and presses A, second does the same, the game syncs them automatically (dual retinal scanner explicitly covered) [VERIFIED - XBM p.27, PRIMA (which adds that this makes synchronized puzzles easier when playing online without headset)].

### C3. Voice chat
- Xbox Live: Xbox Communicator headset recommended; guards can HEAR your voice (proximity voice detection). You can deliberately lure/distract guards by talking; options menu can disable voice detection and set its sensitivity (default 50 = about 2 m in game). Other options: voice through TV speakers, voice masking, Quick Match restricted to headset users [VERIFIED - XBM pp.22, 26; PRIMA; GF preview].
- GF preview adds: whistling into the headset can attract a guard without a button press [SINGLE SOURCE - GF].
- PS2: USB headset supported for online play (the manual frames it for teammates/session lobby), but PS2/GC co-op is split-screen only, so headset co-op does not apply on PS2/GC [VERIFIED split-screen-only - PRIMA + GF; headset text SINGLE SOURCE - PS2M].
- PC: online/LAN co-op existed (ubi.com, servers since shut down); PC voice chat specifics not found [Gap].

### C5. HUD, partner indicator, OPSAT
- Xbox co-op HUD elements: life bar, light meter, noise meter, interaction system, selected item, communication box, objective icon, ammo, **Teammate status (partner's health)**, **Co-op Action key icon (appears when partner is ready for a co-op move/interaction)**, alarm indicator, **chat box** [SINGLE SOURCE - XBM p.23].
- PS2 co-op HUD list: life bar, light meter, noise meter, interaction system, selected item, communication box, objective bar, objective icon, ammo, Co-op action icon, timer, alarm indicator - no teammate-health item and no chat box listed [SINGLE SOURCE - PS2M].
- Agents are told apart by goggle light colour: blue (Agent One), red (Agent Two) [SINGLE SOURCE - FW].
- On-screen partner marker / waypoint: none described in any manual or Prima [Gap - not found].
- OPSAT: Xbox co-op diagram maps OPSAT to Back [XBM]. PS2M says the OPSAT map is displayed "in Solo mode", implying no map in co-op on PS2 [SINGLE SOURCE - PS2M, UNCERTAIN]. CT's OPSAT 3D map shows allies (FW OPSAT page, generic) - whether it shows the partner in co-op is not confirmed [Gap].
- Signposting: training uses blue wall panels with a "Replay Tips" option, and striped squares on the floor mark co-op move spots [SINGLE SOURCE - IGNW training]; contextual moves appear as named entries in the HUD Interaction menu ("Initiate/Complete Rappelling", "Initiate/Complete Hangover", "Initiate Climb Shoulder"/"Complete Climb On", "Accept View Sharing", "Share Equipment") [VERIFIED - XBM + PRIMA]; mission notes in OPSAT give hints like "climb on your partner's shoulders" to disable tanks (Seoul) or "use the jammer" on the turret [SINGLE SOURCE - RUW/FW mission notes]; XBM says the loading screen gives mission clues/hints [SINGLE SOURCE - XBM].

## PART D - Injury, revive, failure, saving

- At zero health in co-op an agent is not killed outright: he falls unconscious ("knocked unconscious" / "critically wounded") [VERIFIED - XBM, PS2M, PRIMA; FW Cooperative page says the injured player must wait for the partner].
- Revive: partner goes to him and picks the heal interaction from the Interaction menu (Xbox A / PS2 X); PRIMA says it is an adrenaline shot restoring about half health; RUW says the adrenaline syringe restores 50% [VERIFIED - XBM, PS2M, PRIMA, RUW].
- Time limit: about 30 seconds to reach the downed partner, otherwise the mission fails [VERIFIED - XBM, PS2M, PRIMA].
- Number of revives: both manuals say revive can only be used **twice per game** [VERIFIED - XBM, PS2M]. PRIMA's basics page says each agent carries two adrenaline shots, but PRIMA's own Xbox/PC gear boxes and RUW tables give 1 syringe per agent per mission (= 2 per team), whereas PS2/GC sub-levels give 2 per agent (FW) [CONFLICT - most consistent reading: Xbox/PC 1 each per mission (2 revives per team), PS2/GC 2 each per sub-level; UNCERTAIN].
- Communication: when an agent drops, an automatic message tells the partner he needs help [SINGLE SOURCE - PRIMA].
- Both down: no source explicitly states it; implied failure because nobody remains to revive within the 30 s window [UNCERTAIN - Gap].
- Exploit/quirk: in Chemical Bunker you can skip the lift by jumping down the shaft onto/near your partner and then reviving him (fall damage downs rather than kills) [SINGLE SOURCE - RUW].
- Versus comparison: spies "nurse" each other via HUD interact (Xbox/PC) [SINGLE SOURCE - PRIMA].
- Other mission-failure triggers seen in co-op: killing the VP (Panama), Jong's death or escape by boat (Seoul), touching laser between paired bombs (Train Station), metal detector alarm or general alarm / being seen in lit windows (UN HQ), lethal force on UN staff not allowed [VERIFIED - FW/RUW mission pages + PRIMA for Seoul/Train Station]. PS2/GC: reportedly 3 alarms fail a sub-level (agent brief; not re-verified here) [UNCERTAIN].
- Saving / checkpoints:
  - Xbox: "Save Game" stores Story progress so the same pair can continue in another session (both consoles' saves must match; launching from that save auto-invites the partner); "Quick Save" exists mid-mission but only for the current session, Retry restarts from it [SINGLE SOURCE - XBM pp.27-28].
  - PS2/GC: progress saved at the end of each area (sub-level); unlocked areas replayable in any order; Hall of Fame stores high scores [VERIFIED - PRIMA + PS2M].
  - Scoring: success rating combines both players' stats; civilians killed cost points, KOs do not; perfect score requires no kills/injuries, no alarms/identification and all objectives [VERIFIED - XBM, PS2M, PRIMA].
