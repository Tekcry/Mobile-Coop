# S3 fragment: measured checks (for D-A)

Owner: validator-port S3. Status: current until D-A folds it into `docs/level-validator/graph-schema.md` ("Schema
additions", "How the checks read the graph") and `docs/level-design.md` 15 (the measured line).

Code: `scripts/level-checks/measured.mjs` (`checkMeasured(graph, metrics, { requireMeasured })`, V6d port, BRIEF A4,
A5, lead answer L2). Tests: `tests/levelMeasured.test.ts`.

## Schema rows (add to V6's "Schema additions" table)

| Field | On | Shape | Meaning |
| --- | --- | --- | --- |
| `meta.measured.ways_back` | meta (campaign) | `[{ from, to, kind, back_s, path_m }]` or `{ from, to, kind, back_s: null, why }` per entry | One per co-op link, graph order: the solo nav time from the link's `to` floor back to its `from` floor at `reach_speed_mps` (level-design 11.6). Written by `level-measure --write` on campaign graphs only |

V6's `meta.measured.splits.<id>` keeps `{ a_s, b_s, reach_s }`; `a_s` / `b_s` are the measured leg times (null when a
leg is not timed).

## What the measured check does

| Check | Severity |
| --- | --- |
| Encounter space with no `measured` | INFO "pending V6"; ERR under `--require-measured` |
| Measured `sees_pct` below `vantage_min_frac` (encounter) | ERR |
| Measured `los_break_s` over `los_break_max_s` (encounter) | ERR |
| Measured `shadow_pct` outside `shadow_min_frac` - `shadow_max_frac` (encounter) | INFO, every mode, flag or not (G329, V1) |
| Measured `shadow_pct` apart from the declared one by more than 0.10 | INFO |
| Measured `sees_pct` (0.10), `los_break_s` (1.5 s) or link `time_s` (1.5 s) apart from the declared value | WARN (update the declared target) |
| Measured value that is not a number (null = not measured) | ERR |
| Split `a_s` / `b_s` over `split_max_s`, or apart by more than `split_parity_pct` | ERR |
| Split `reach_s` over `reach_max_s` | ERR |
| Split `reach_s` null | WARN; the core's declared reach check still runs (L2) |
| Declared split with no `meta.measured.splits.<id>`, or no `a_s`, `b_s` or `reach_s` | ERR under `--require-measured` |
| `meta.measured.splits.<id>` naming no split | WARN |
| Campaign co-op link with no matching `ways_back` entry (from / to / kind) | ERR under `--require-measured` |
| Way back `back_s` over `reach_max_s` | ERR (not on a two-way gate: a passed `pair_gate`, `shutter`, `plank_bridge`, `deadweight` or `vent_unlock` is its own way back, as in the core gate reach) |
| Way back `back_s` null | WARN with its `why`; the core's declared way back still runs (L2) |
| `ways_back` entry naming no co-op link | WARN |

The 0.10 and 1.5 s drift tolerances are tooling constants in the script (as V6), not level numbers. Split legs, partner
reach and gate reach in the core read a link's `measured.path_m` / speed first (A6, `linkTime`).
