## 1. Behaviour (exact)

1. `?sectorStart=N` (N one digit 1-9; anything else ignored) makes every Sector Ops run started on that page (host or
   solo) begin at section N. N = 1, N past the map's last section, or a section with no connector before N: a normal
   run, nothing changes. Read in every build (like `?sectorGuards`): the walk opens `/preview/`, a production build.
2. The run begins as if sections 1..N-1 had been cleared through their connectors (what `SectorRun.advance` and
   `connEvents` leave): run index N-1, phase objective, the checkpoint (and partner point) = connector N-1's
   `checkpoint` / `checkpoint2`, alarm stage 0 recorded as the section's start, the connector machine locked. Every
   connector 1..N-1: near door locked (as `findDoors` left it), far door unlocked and opened silently, its `sealUnlocks`
   doors unlocked. The `objective`-kind intel codes of sections 1..N-1 are held (no radio line). Sections 1..N-1 are never
   loaded (no guards, devices, bodies) and never rated (their marks stay -1). Section N loads exactly as on a connector
   load (`loadSection(N-1)`, `beginSection()`: guards on their routes, devices live, the lamp / door start state, the
   loadout recorded). The player spawns at that checkpoint; a down or the pause menu's restart restarts section N there.
3. Such a run is **practice**. Nothing goes to the save: no difficulty star (`markCompleted`, host and co-op client), no
   best section rating (`updateRatingRecord`), no progression (`GameState.rewardHook` / `applySession`). Ratings still
   show (card, results lines) and still grant; the HUD reads "Section N/n". The results line drops its badges ("PERFECT"
   once sector-batch lands, "GHOST") and ends `  ·  PRACTICE from section N`. The extraction banner is left as is
   (display only; its line belongs to sector-batch B1, section 7).
4. Works on every Sector Ops map, so with `?campusv2=N` (once P0's flag is on master) and with v1: the start reads only
   `map.sectors`, whichever layout built them. Walk link: `/preview/?campusv2=3&sectorStart=3`, then Main menu > Sector
   Ops > Saltmarsh Park > Normal > Start.
5. Co-op: the host's link wins. A client never builds `SectorMode` (`gameState.ts:697`, the puppet branch; the mode is
   made only at :731 in the else branch), so it never reads its own `?sectorStart`. It starts where the menu puts it today
   (`CoopClient.placeStart`, section 1's start); on its first state the host sees it outside the current section and puts
   it at the checkpoint with the existing `restore` event, repeated until it stands there (`firstPlace`, 2.6). From then
   it follows the host's `sector` message as in any run (`ls` live section: devices, bake, loadout record; `lk` door
   locks; the HUD line via the snapshot). It treats the run as practice when the last `rh` it got has section 1 unrated
   (`packRated`'s -1; a normal run always rates section 1 at its connector, or at the extraction on a one-section map),
   so it records no star and no progression. Solo and 2 players must work; 3-4 players take the same path (each remote
   gets its own slot spot from `joinSpot`).
6. **Wire: none.** No new message, field or event: `restore`, `sector` (`ls`, `lk`, `rh`) and `end` (`subtitle`) are on
   master. `practice` on `SessionStats` never reaches the wire (`CoopHost.onEnd` :1951-1959 sends named fields only).
   No `PROTOCOL_VERSION` or `SAVE_VERSION` effect.

### 2.1 `src/game/sectorStart.ts` (new, pure: no Babylon, no `flags`, no allocation except the one end line)

```ts
/**
 * (campus-greybox A28) The start-at-section link (`?sectorStart=N`, `flags.sectorStart`): a Sector Ops run that begins
 * at section N as the connectors before it leave the run (`SectorRun.advance`): index N - 1, the last connector's
 * checkpoint, the alarm stage (0) as the section's start; the earlier sections never loaded or rated. Such a run is
 * practice: nothing goes to the save (`SectorMode.practiceFrom`). Pure; `sectorMode.ts` puts it in the world.
 */
import type { SectorDef, SectorRun } from './sectors';

/** The run index `?sectorStart=n` asks for (n: the 1-based section number): 0 (a normal run) when n is absent, below 2,
 *  not a whole number, past the last section, or behind a section with no connector (no cycle could reach it). */
export function sectorStartIndex(defs: readonly SectorDef[], n: number | null): number {
  if (n === null || !Number.isInteger(n) || n < 2 || n > defs.length) return 0;
  for (let k = 0; k < n - 1; k++) if (!defs[k]!.connector) return 0;
  return n - 1;
}

/**
 * Put a fresh run (index 0, objective phase) at section `i` as `SectorRun.advance` leaves it once connector i - 1 seals:
 * the index, that connector's checkpoint and partner point, no download, the connector machine locked, the alarm stage
 * recorded as the section's start. The earlier marks stay -1. False, the run untouched, when `i` is not a section after
 * a connector or the run has already moved.
 */
export function applySectorStart(run: SectorRun, i: number): boolean {
  const c = run.defs[i - 1]?.connector;
  if (i <= 0 || !c || !run.defs[i] || run.index !== 0 || run.phase !== 'objective') return false;
  run.index = i;
  const cp = run.checkpoint;
  cp.x = c.checkpoint.x;
  cp.y = c.checkpoint.y;
  cp.z = c.checkpoint.z;
  cp.yaw = c.checkpoint.yaw;
  run.checkpoint2 = c.checkpoint2 ?? null;
  run.progress = 0;
  run.downloading = false;
  run.conn.reset();
  run.alarmAtStart = run.alarm;
  return true;
}

/** The badges a practice run does not earn, as `sectorResult` writes them (the separator is `sectors.ts`'s). */
const PRACTICE_DROPS = ['  ·  PERFECT', '  ·  GHOST'] as const;

/** A practice run's result line: `line` (from `sectorResult`) without its badges, then "PRACTICE from section N". */
export function practiceLine(line: string, from: number): string {
  let out = line;
  for (const b of PRACTICE_DROPS) out = out.replace(b, '');
  return `${out}  ·  PRACTICE from section ${from}`;
}

/** Co-op client: the host's run never rated section 1 (`rh[0]` -1, `packRated`'s unrated), so it began at a later
 *  section: practice (no star). No allocation (read per `sector` message). */
export function practiceFromRh(rh: readonly number[]): boolean {
  return (rh[0] ?? -1) < 0;
}
```
