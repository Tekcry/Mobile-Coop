# Art credits

Every external file the game or its offline pipelines use, with its source and licence (bible 5.14, 5.16, Section 6).
Only CC0 files are allowed: CC0 textures for desktop detail and the CC0 base human body of the operator pipeline.
The one exception is the menu font (menu-ui MD1, SIL OFL 1.1), listed under "Fonts".
Assets generated by scripts in the repo are not external and are not listed. All are bundled and never fetched at runtime.

Add a row before the file is committed. Reference data that never ships (for example survey tables used to check
proportions) is listed under "Reference data" and kept out of the repo.

## Motion capture (CMU exception, mocap-trial)

The one non-CC0 data source: Michael's exception for CMU motion capture only (docs/mocap-trial/BRIEF.md, 2026-10-22).
Raw takes stay out of git (`.mocap-cache/`, gitignored); only clips converted onto Wren are committed and bundled.
Every take used, with its seconds: `docs/mocap-trial/SOURCES.md`.
