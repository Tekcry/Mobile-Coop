# Proposed perception change: measured, not applied

Generated by `map-dead-line-v2-perception.mjs` (2026-10-10). The engine (`src/ai/perception.ts`) is unchanged.

**Proposal.** Inside the focus cone and within 8 m, a target in dim light gets a second fill rate that does not use the squared light factor:
`dim = 1.8 x (1 - d / 8) x k x stance x motion x exposure`, where k rises from 0 at light 0.2 to 1 at 0.28 (darkness below 0.2 is untouched). The guard uses the larger of this and the normal rate. For a crouched player moving at 1.8 m/s in light 0.28 this is 0.99/s at 0 m, 0.50/s at 4 m and 0.25/s at 6 m (just above the 0.2/s leak: noticed within about 6 m); in bright light (0.6) the normal rate at 6 m is 0.80/s, so dim still fills slower. It would go in `PERCEPTION` as a config block (`dimNear: { from, full, range, rate }`, `rate: 0` = off).
