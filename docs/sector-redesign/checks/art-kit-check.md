## Polish list (not blocking; file:line, what, why, suggested fix, dresser API change?)
- **P1 (recommended before the dressers are integrated) - generated ledges are not protected or gated.**
  - Where: `keepouts.ts:413` (K11 covers placed anchors and split gaps only) and `tests/campusArtGameplay.test.ts` (no ledge item). Builder log L19.
  - What: ledges are generated in `LevelBuilder.build` after dressing. `generateLedges` (`anchors.ts:317`, `cutLip`) cuts a greybox lip wherever any collide box, art boxes included, rests on it or sits in the hang space (0.2 m out, top - 0.3).
  - Why: ART-PLAN 4.3 K11 lists "ledges in use". Floor props near route legs are kept off by K1 + `navClear`, but wall-mounted and raised placements skip K1 / K2 (see P2), and nothing reports a lost ledge.
  - Fix (test only): add gate item 11 to `campusArtGameplay.test.ts`. Run `generateLedges(bG.boxes)` and `generateLedges(bD.boxes)` (pure). Every greybox ledge (`piece <= nGrey`) with a sample point within `KEEP.route` of a section's K1 leg (same storey band), or within `KEEP.lipReach` of a section lip, must still be covered by a dressed ledge on the same piece and normal (span within 2 cm). Fail naming the ledge, the piece and the nearest art box.
  - Dresser API change: none.
- **P2 - the mount derivation lets raised boxes skip the floor keepouts.**
  - Where: `keepouts.ts:592`.
  - What: `placementMount` returns `'ceiling'` for any piece raised more than 5 cm with no wall behind it, whatever its height, so a solid or see box at body height off a wall (a hero `add` at the wrong `y`) skips K1-K6, C, K7 rules 2 and 3, and K12. `add` and `d.check()` then accept it.
  - Why: the gameplay gate still catches the nav, cover and lip effects, but K12 (glass) is not gated, and the dresser gets the error late.
  - Fix: return `'ceiling'` only when the piece's bottom is at least `floorUnder + 1.9`; otherwise `'floor-free'`.
  - Dresser API change: none to the signatures, but it can drop a few more `base()` candidates, so land it after the five dressers merge and rerun their gates.
- **P3 - long legs that cross a section are dropped.**
  - Where: `keepouts.ts:314`.
  - What: `cap()` drops a leg when both endpoints lie outside the section bounds plus margin, even if the leg crosses the section.
  - Fix: use a segment-to-rect distance test.
  - Dresser API change: none.
- **P4 - the gate never checks split gaps.**
  - Where: `tests/campusArtGameplay.test.ts:59`.
  - What: the gate's contexts pass `() => []` for splits, so the gate's `checkDressing` never checks K11 split gaps (the dresser path does).
  - Fix: pass `findSplitGaps(buildCoverSegments(bG.boxes, bG.cylinders))`.
  - Dresser API change: none.
- **P5 - split gaps depend on the dressing order.**
  - Where: `maps/campusDress.ts:101`.
  - What: the split gaps are computed lazily at first use, so they include the art boxes of the sections dressed before it. The result is deterministic but depends on order.
  - Fix: compute them from the greybox before the loop (only when any section has tags).
  - Dresser API change: none.
- **P6 - `?voxels=1` shows both the box and the skin.**
  - Where: `levelBuilder.ts` `hidePieces`.
  - What: boxes drawn as voxels are skipped, so under `?voxels=1` (a comparison flag, off by default) a car shows its box and its skin.
  - Fix: none needed unless voxels return.
- **P7 - the detail pass decorates art boxes.**
  - Where: `levelBuilder.ts:452`.
  - What: the detail pass decorates every collide visible box, so tall solid art boxes (2.2 m+, thin) can get conduit, sign and skirting detail pieces that clash with the skin. This is visual only.
  - Fix: skip boxes past the greybox count, or mark art boxes `detail: true`, when the dressers use tall solid runs.
- **P8 - a failed build leaks meshes.**
  - Where: `campusArtRender.ts:101-111`.
  - What: if `build` throws part-way, the meshes it already made stay in the scene until the scene is disposed. The greybox still shows.
  - Fix: catch inside `fromModels` and call `r.dispose()` before rethrowing.
- **P9 - dressing cost per load.**
  - What: with all five sections' tags, `dressCampus` cost about 0.84 s in node (builder trial), paid on every campus load by host and client.
  - Fix: worth a look in the perf pass.
