## The rule (BRIEF A12-A15), with `flags.sectorOutWait` on, host side
- A downed player whose 30 s window runs out, or who goes down with no syringe left, is out (`coopHost.goOut`). If
  anyone is still up, the section does not restart: the mode records the out player and shows "OPERATOR OUT" / "Back
  at the next section door". If nobody is up, the restart runs as now.
- Out players do not count for the connector's "everyone inside" or the extraction (`sectorMode.exitStep`); a player
  downed with a running window still counts (A20 of feature/sector-ops).
- When the connector's cycle completes (`CONN_UNLOCK_FAR`, after `beginSection()`), every player not up comes back on
  the new checkpoint's slots (no syringe used, windows cleared). A section restart clears the out set (the respawn
  already brings everyone back).
- With the flag off, every line behaves exactly as on master.
