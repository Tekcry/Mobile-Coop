its picture and meter have k's lamps from the first frame (CONFORMANCE L7; `docs/sector-redesign/checks/

## Steps
1. Wire (`src/net/protocol.ts`): add `ls?: number` to the `start` variant (`:285`). Parser (`:944-951`): accept 1..63
   (`num(raw.ls, 1, 63)`, then `Math.round`, as `bay` is); out of range or absent leaves it off. Do not touch
   `PROTOCOL_VERSION` (`:21`).
2. Session (`src/net/session.ts`): `StartInfo.ls?: number` (`:16-26`); `lateSection: (() => number) | null = null`
   beside `lateBay` (`:72`); in the late-join send (`:190-195`) add `ls` when `lateSection?.()` returns > 0; the client
   copies `msg.ls` into `this.start` (`:251-255`); `startMsg` (`:380-383`) passes `ls` through when set. A match start
   (`startMatch`) never sets it.
3. Host (`src/net/coopHost.ts`): `sector()` (`:818-820`) records `extra.ls` in a field (`lastLs`, start -1); beside
   `s.lateBay = ...` (`:240`) set `s.lateSection = () => (this.lastLs > 0 ? this.lastLs : 0)`; clear it where `lateBay`
   is cleared (`:1971`). Do not read the host's own bake: a host with a full cache hit has no `SectionBaker`, while its
   joiner may still miss and bake.
4. Client UI (`src/net/coopUi.ts:198-212`): pass `sectionStart: s.ls` in the `startGame` options.
5. Game (`src/game/gameState.ts`): `GameOptions.sectionStart?: number` (`:148`, doc comment: co-op late join only);
   pass `liveSection: opts.sectionStart` to `World.create` (`:926`). Leave the wait at `:968-975` as it is (it waits for
   `sb.plan.live`, which is now the hinted section).
6. World (`src/world/world.ts`): `WorldOptions.liveSection?: number` (`:58-64`); pass it to `bakeLevelLight` (`:192`)
   as `live`.
7. Bake (`src/world/lightBake.ts`): `LightBakeInput.live?: number`; pass `live: inp.live` to `new SectionBaker` (`:108`).
   Out of range is already ignored by `SectionPlan.setLive`. A cache hit or a map without section bake ignores it.
8. Docs: in `docs/systems/lighting.md` "Per-section lamp bake", replace "the client's `ls` move the live section first
   (no wire change)" with one sentence: a late joiner's `start` carries the host's live section (`ls`), so its load bakes
   and waits for that section first; the client's `ls` moves it later. Keep everything else.
9. Fragment `changes/feature-light-parity-net.md` (`kind: patch`): "Co-op: a player who joins or rejoins Saltmarsh
   Park in a later section sees that section's lights from the start." (N2 adds its line.)
