## Goal
One required GPU suite proves bible L5 on every carded map at Low and Epic: grey cards at field levels matching each
`DARK_TARGETS` row read as display luma inside the row's band, and the light meter equal to the field at every card,
with flicker pinned (CONFORMANCE L8, V3, V4, V5, V8; Test Runner T3).

## Steps
1. `scripts/parity-lib.mjs`: move out of `scripts/e2e-darkness.mjs` (no behaviour change for the night-vision and
   thermal parts that stay): `measure` (`:100-128`), `readLuma` (`:130-146`), `readRgb` (`:148-172`) and the in-page
   probe search (`findProbes` `:26-98`), generalised to take `{ levels, rect, step, y, minCards }` and return candidates.
   Add pure helpers (no page, no Babylon), exported for the unit test:
   - `rowFor(level)`: the `DARK_TARGETS` row a card level is held to, or null. Rows and bands copied from
     `src/world/darkCurve.ts:86-91` into one `DARK_TARGETS` constant here. 0.12, 0.40, 0.70 rows: `|level - row| <=
     0.03`. The 0.27 row: `|level - 0.27| <= 0.02` and `level < 0.28` (A6). 0.28 <= level < 0.31: null.
   - `inBand(luma, row)`: `row.min - 1e-3 <= luma <= row.max + 1e-3`.
   - `knownFor(miss, KNOWN, now)`: the entry with the same map, section and row whose `near` is within `r` m of the
     card, or null; an entry with `until` before `now` never matches (it fails as a plain miss).
   - `summaryLine(part, results)`: `PARITY-SUMMARY ` + one-line JSON `{"part":n,"cards":{"ok":a,"total":b},"meter":
     {"ok":c,"total":d},"known":[ids],"misses":[ids]}`.
   - `pinFlicker(page)` / `unpinFlicker(page)`: in the page, keep `reg.tickFlicker`, replace it with a no-op, set
     `reg.lights[id].flicker = 1` for every id in `reg.flickering`, `reg.flickerVersion++`; unpin restores the function
     and bumps `flickerVersion` (`src/world/lights.ts:170`, `:246`, `:278`).
2. `scripts/e2e-darkness.mjs`: import the moved functions from `parity-lib.mjs`; delete its four grey-card rows and
   their loop (they move to `e2e-parity` part 4, A13); keep night vision (`NV`) and thermal exactly as they are.
3. `scripts/e2e-parity.mjs` (`--part=N`, as `e2e-sectorops.mjs:16-17`; no part = all):
   - First line: if `process.env.E2E_GPU !== '1'`, print `E2E ERROR: e2e-parity reads final pixels: E2E_GPU=1 only` and
     exit 1.
   - `LOOKS`: `low` (`gfx=low`) and `epic` (`gfx=epic`), one browser each per part (`launch` from `e2e-lib.mjs`).
   - Parts: 1 campusOps S1-S2, 2 campusOps S3-S5 (`autostart=campusOps&mode=sector`, sections = the first rect of each
     `CAMPUS_BAKE.regions` entry (`src/world/maps/campusBake.ts:16-27`) copied into a `CAMPUS_RECTS` constant in
     `parity-lib.mjs` (the page cannot import it; the unit test asserts the copy); wait until every section's lamps
     landed: `world.lightBake.sections` null, or `whenReady(k)` for every k), 3 ctcourse (`autostart=ctcourse&mode=course`,
     the whole map bounds), 4 warehouse (`autostart=warehouse&mode=clear`, as e2e-darkness did). Not carded: every
     other map (A1, A5). Guards: freeze AI and park every character more than 4 m from any candidate (as `findProbes`
     `far` did).
   - Cards: per campus section at least 3 (V4), ctcourse at least 8, warehouse one per row. Pick per section one point
     per row that has a candidate (steadiest, as `findProbes` does), then fill up to the minimum from the remaining
     rows' next-best candidates spread at least 6 m apart. A section with fewer than its minimum fails with the levels
     it found.
   - For each card and look: `pinFlicker`, `measure` (night vision off), `rowFor` and `inBand`; a miss checks
     `knownFor`. Then the meter row at the same point: put the operator's feet there (standing), step the loop headless
     0.3 s (the meter samples at 10 Hz), read `g.lightLevel` and `g.world.lightField.bodyLevel(x, feetY, z, h, g.lightOccluder, 0, 0)` with
     the standing `h` the meter uses (`src/game/gameState.ts:1665-1690`; read the code for `h` and the field handle), `|meter -
     field| <= 0.02`. `unpinFlicker` at the end of the look.
   - Card id: `<map>:<section>:<row>:<x>,<z>` (one decimal). Print one line per card:
     `<look> <id> level <l> luma <v> band <min>-<max> ok|MISS|KNOWN MISS (<conf>)` and per meter row
     `<look> <id> meter <m> field <f> ok|MISS`.
   - `KNOWN = []` (A2): entries `{ map, section, near: [x, z], r, row, conf, owner, until }` are added by the lead only.
   - End: `summaryLine` for the part; exit 1 on any non-known miss, any section under its minimum, a console error, or
     an expired `KNOWN` entry that matched.
