## Interfaces (exact)
```ts
// src/game/charOccluderFill.ts (pure: no Babylon, no rig, no graphics state, no src/net, no PlayerRef / Enemy import;
// no allocation after module load)
import { OCC, OCC_KIND, occKey, type CharOccluders } from '../world/charOccluders';

/** The interim fill (BRIEF A10): today's `rtCapsule` numbers (gameState.ts:3643-3653), the guard cull, player slots
 *  (MAX_PLAYERS 4, src/net/protocol.ts:23, restated here: single player never imports src/net). */
export const FILL = { r: 0.22, footLift: 0.25, topDrop: 0.2, minTop: 0.5, reach: 30, players: 4 } as const;
/** `pin` stride per player slot: feet x, y, z; sample height h (the meter's); head offset ox, oz. */
export const FILL_IN = 6;
/** A guard or a client's puppet (`TakedownVictim` fits it structurally). */
export interface VictimLike {
  readonly alive: boolean;
  readonly pos: { readonly x: number; readonly y: number; readonly z: number };
  readonly def: { readonly height: number };
}
/** `occ.clear()`, then per slot s < n one upright capsule: a = (x, y + footLift, z), b = (x + ox, y + max(minTop,
 *  h - topDrop), z + oz), r; owner `occKey(OCC_KIND.player, s)` into `keys[s]` (-1 when the contract is full). */
export function fillPlayers(occ: CharOccluders, pin: Float64Array, n: number, keys: Int32Array): void;
/** Every `alive` victim in list order whose feet are within `FILL.reach` (hyp2, horizontal) of any player slot in
 *  `pin`: a = (x, y + 0.25, z), b = (x, y + max(0.5, height - 0.2), z), r 0.22, owner `occKey(OCC_KIND.guard, i)`,
 *  i = its list index. Returns how many did not fit (0 unless the contract is full). */
export function fillVictims(occ: CharOccluders, vs: readonly VictimLike[], pin: Float64Array, n: number): number;
/** The picture's capsules in `BakedLamps.capsules` layout (bakedLamps.ts:229, read at :505 and :700-708: a = foot
 *  x, y, z, r; b = head x, y, z): players in contract order first, then the others nearest pin slot 0 (the local
 *  player; squared horizontal distance of the capsule midpoint, ties by slot); at most `max`; returns the count. */
export function pictureInto(occ: CharOccluders, a: Float32Array, b: Float32Array, max: number, pin: Float64Array): number;
```
Capsules are written by a module-private `put(occ, kind, index)` that reads the 7 doubles from a module
`Float64Array(7)` and writes `occ.cap` / `occ.owner` / `occ.n` exactly as `CharOccluders.add` does
(charOccluders.ts:60-76): `add` takes 7 doubles, which V8 boxes (16 B each) at a call it does not inline.

GameState (new members):
```ts
/** (char-shadow-meter S2) The character contract, filled every sim step from the sim; null with the flag off. Guard AI's
 *  `fillOccluders` and Player's `fillOperator` replace the interim fills later (PLAN section 6). */
readonly charOccluders: CharOccluders | null = flags.charShadowLight ? new CharOccluders() : null;
private readonly lightIn = new Float64Array(FILL.players * FILL_IN);
private readonly charKeys = new Int32Array(FILL.players);   // S3b-2 passes these to ShadowCues.fill
private readonly charRefs: PlayerRef[] = [];                 // playerRefsInto order (slot 0 local), S3b-2 reuses it
private charN = 0;
private charFull = 0;
private readonly charCapsules = (a: Float32Array, b: Float32Array, max: number): number =>
  pictureInto(this.charOccluders!, a, b, max, this.lightIn);
```

## Hot-path rules (fillChars runs every sim step, pictureInto every render frame, the meter at 10 Hz)
- Nothing allocates, even un-inlined: no closures, iterators, `for...of`, spread, destructuring into new objects,
  array / object literals or `new` in these paths. Doubles never cross a call you add: write them into a typed-array
  slot and pass small ints / object references (the pattern of lightField.ts:203-205 `pushLv` and :268-286, and
  `CharOccluders.q`, charOccluders.ts:50-52). A double kept in a class number field is not a slot (CI's V8 boxed
  `res` stores, commit 97ca3ad28).
- `hyp2` / `hyp3`, never `Math.hypot`. No string building outside the debug closure.
- The existing `bodyLevel` boxing (its public double arguments, within `BOXED_BUDGET` 72 B, tests/lightField.test.ts:124)
  is S1's, not added here.
- No graphics reads: the fill takes heights from the sim (`rig.height` only as today's meter does, gameState.ts:1673;
  never the head node, which `rtCapsules` reads for the picture).
