# Mocap trial - side-by-side sheets

Generated by `scripts/mocap-sheets.mjs` (do not edit by hand: rerun it). Each sheet: the `?mocap=0` strip (the
hand-keyed set, the game as it is) above the `?mocap=1` strip (the mocap set), the same sim times frame for frame
(sim-time stepped, `loop.manual`), Proving, `gfx=high`, holstered, standing. Views: `side`, `front`, `34` (front
three-quarter, her right); the turn rows keep the cameras on her start heading. Each cell: sim time, motion state,
speed (m/s), planted feet, gait phase; mocap=1 cells also `mc` (the mocap share of the keyed pose) and `cf` when
clip feet are on; the lower strip prints its pixel difference from the frame above it. The `.webm` per row shows
the 3 views x 2 sets at real speed (the cycle rows loop 3 times; the event rows hold their last frame).

Rerun (desktop GPU, port 4192, after `npm run build`): `E2E_GPU=1 E2E_PORT=4192 node scripts/mocap-sheets.mjs`
(`--rows=walk,stop` for some rows only; the others keep their entries).
