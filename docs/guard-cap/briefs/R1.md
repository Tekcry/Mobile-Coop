## Why
CLAUDE.md hard rule: hot paths must not allocate. `losClear` (`src/ai/perception.ts:80-82`) calls `b.ray`, which
allocates on every call (`src/weapons/ballistics.ts:115-136`: a `RayHit` object plus `to.clone()` and `Vector3.Up()` on a
miss, `hitPoint.clone()` and `hitNormal.clone()` on a hit). It runs on every think for every guard (`enemy.ts:2351`, called
from the sight checks around `enemy.ts:2228-2240`), so at 24-32 guards it is a steady GC source. The same pattern sits in
the recon drone (`src/ai/reconDrone.ts:179-180`).

## Change
1. `src/ai/perception.ts:80-82` `losClear`: widen the first parameter to
   `{ ray(...): { hit: boolean; distance: number }; hitDistance?(from: P3, to: P3, mask: number): number }`.
   When `b.hitDistance` exists, use it: clear when `b.hitDistance(eye, to, MASK.SIGHT) > hyp3(to - eye) - slack`.
   Otherwise keep today's `ray` path (test doubles, editor callers). `Ballistics.hitDistance` (`ballistics.ts:83-88`)
   returns the segment length on a miss, so a miss stays clear for any slack >= 0: same verdicts as
   `!hit || dist > len - slack`. Check the `P3` vs `Vector3` typing: `hitDistance` takes `Vector3`; every live caller
   passes `Vector3`s, so either type the optional method on `Vector3` or keep `P3` if Babylon's `Vector3` satisfies it
   structurally (no casts that hide a real mismatch).
2. `src/ai/reconDrone.ts:179-180`: `this.ballistics.hitDistance(this.eye, this.to, MASK.SIGHT) >
   Vector3.Distance(this.eye, this.to) - 0.3` (or `hyp3` on the components; no new vectors).
3. Leave `Ballistics.ray` as is: its other callers are per shot (`enemy.ts:3399`, player weapons) or per player action.
   `src/editor/security.ts:419` `SightRay = Parameters<typeof losClear>[0]` and `src/editor/lightView.ts:500-503` must
   still compile and behave the same (the method is optional).
4. Out of scope (note only, not this slice): `src/game/takedownController.ts:313/346`, `teamController.ts` rays and
   `gameState.ts:3130` also use `ray` for yes/no tests; they are per player action, not per guard think.
