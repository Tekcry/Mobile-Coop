## Change
1. `EnemyPuppet`: a `private readonly tier: GuardAnimTier | null`, built in the constructor for a non-dog rig:
   `new GuardAnimTier(scene, this.rig.voxel?.meshes[0] ?? null, seedOf(id) & 1023)` (the slot staggers solves as the
   host's `this.num`).
2. `update(dt, renderTime, players: readonly { feet: Vector3 }[])`: replace `this.rig.animate(dt, rp)` (:500) with the
   host's three steps: `if (gb) tier.watch(gb.viewMesh)`; `tier.animate(this.rig, dt, rp, players, pinned)` with
   `pinned = this.taken || this.remoteHold || this.rig.emote !== null`; `if (gb) gb.skip = tier.skipped`. The dog path
   (returns before) is unchanged. `?animtier=0` turns puppets off too (`GuardAnimTier` reads `flags.animTier`).
3. Gameplay unchanged; say why in a comment. Hit judging: the head volume is `guardHead` on `puppetHeadIn`'s wire inputs
   (:483, :502-504), never the rig, and `hitboxes.sync(this.pos, this.head)` still runs every frame; the host judges a
   client's shot on its own rewound history (`rt`). Torches come from pos / yaw / st (`TorchHolder`, `torchMirror.ts:15-24`),
   takedown reach from `pos`. A skipped solve changes only pixels.
4. `die()`: when `tier.skipped`, `tier.solveNow(rig, 0, this.rp)` before the rig goes to the ragdoll (as host
   `enemy.ts:2091`, `:3840`), so the client's ragdoll seeds from a current pose.
5. `coopClient.ts`: one field array of `{ feet: Vector3 }` holders, refilled in place each frame (index 0 the local
   `g.player.position`, then each avatar's `pos`; a holder is added only when an avatar joins; length set per frame),
   passed to `p.update(dt, t, this.tierFeet)`. No spread, `Map` iteration helper or closure per frame.
