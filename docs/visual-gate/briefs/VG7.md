## noiseLib.mjs (pure, all exported, exact names)
Input "runs" are parsed result.json objects (`{ sha, version, renderer, shots: ShotRecord[], rigs: ShotRecord[],
parity: ParityRow[], summary, notRun, runErrors }`, the VG5 shape). A metric address is `<region>.<metric>`, region
`whole`, a region name, or `leak` (rig on keys only: `leak.mean`, `leak.p95`).
- `STATS = ['mean', 'p5', 'p50', 'p95', 'nearBlack', 'veil', 'contrast', 'blotch', 'arc']`, `K_SIGMA = 4`.
- `sd(xs: number[]): number` - sample standard deviation (n - 1); 0 for n < 2.
- `spreadOf(runs): Spread` with
  `Spread = { n: number, keys: Record<string, Record<string, { n, mean, sd, min, max }>>, emd: Record<string, Record<string, number>>, parity: Record<string, { n, mean, sd, min, max, what: 'card-luma' | 'meter-d' }>, missing: string[] }`:
  - a key enters only when it has metrics (no `error`) in EVERY run; else it goes to `missing` (`<key>: <why>`).
  - regions: `whole` always; a named region only when its `n >= MIN_REGION_PX` (gate.mjs) in every run (the gate
    strips thinner ones before compare, so their noise never matters); else `missing` gets `<key> <region>: thin`.
  - per region, every STATS field present (a number) in every run -> `{ n, mean, sd, min, max }` at
    `keys[key]['<region>.<metric>']`; rig on keys also `leak.mean`, `leak.p95`.
  - `emd[key][region]` = sqrt(mean over run pairs of emd(hist_i, hist_j)^2) / sqrt(2) (the per-run sigma equivalent:
    for one value E[(x_i - x_j)^2] = 2 sigma^2).
  - parity: card rows with `skip === null` in every run -> `parity[id]` over `luma` (`what: 'card-luma'`); meter rows
    -> over `meter - field` (`what: 'meter-d'`); a row skipped or missing in any run -> `missing`.
- `tolerancesFrom(spread, floors = FLOORS, k = K_SIGMA): Record<string, Partial<Tolerances>>` (A13, A24). Per key,
  over its regions R (max over R; "m" = the run mean, "s" = sd):
  `meanAbs = k * max s(mean)`; `meanRel = k * max { s(mean) / m(mean) : m(mean) >= 0.05 }`;
  `nearBlack = k * max s(nearBlack)`; `emd = k * max emd[key][R]`; `veil = k * max s(veil)`;
  `contrastDrop = min(0.9, k * max { s(contrast) / m(contrast) : m(contrast) >= 0.05 })`;
  `blotchAbs = k * max s(blotch)`; `blotchRatio = 1 + k * max { s(blotch) / m(blotch) : m(blotch) >= 0.01 }`;
  `arcAbs = k * max s(arc)`; `arcRatio = 1 + k * max { s(arc) / m(arc) : m(arc) >= 0.002 }`.
  A field with no qualifying region is not computed. Each value rounded UP to 4 decimals (`Math.ceil(x * 1e4) / 1e4`).
  Only fields strictly above their floor are written (the gate's `tolFor` takes max(floor, value) anyway); a key with
  no such field is absent. Leak and parity never make tolerances (absolute rules only).
- `selfCompare(runs, tolerances): { pairs: number, floors: Flag[], tol: Flag[] }` - every ordered pair i != j of runs,
  every key in both: `compare(key, stripThin(i.metrics), stripThin(j.metrics), tolFor(key, {}))` into `floors` and
  `... tolFor(key, tolerances)` into `tol` (the same-build false flags before and after VG7).
- `noisy(spread, tolerances, floors = FLOORS): string[]` - lines `<key> <field> <value> (floor <f>, x<ratio>)` for each
  written field over 2 x its floor (ratio fields compare `value - 1` with `floor - 1`); plus `<key> leak.mean 4sd <v> >
  rule 0.004` / `leak.p95 4sd <v> > rule 0.02` and `<card id> 4sd <v> > 0.02 (A15 pad)` / `<meter id> 4sd <v> > 0.02
  (METER_TOL)`. These are findings for VG8, not errors.
- `renderTolerances({ spread, tolerances, source }): string` - the whole `tolerances.mjs` text, deterministic (keys
  sorted, numbers as written): a header comment (generated by `node scripts/visual-gate/noise.mjs spread`, from
  `shots/visual-gate-vg7/<sha8>/run1..3`, the date, the renderer, rule A13 / A24, "regenerate, never hand-edit; VG8
  reads SPREAD for its 4-sigma test"), then
  `export const SOURCE = { sha, version, renderer, runs, at };`
  `export const TOLERANCES = { '<key>': { field: value, ... }, ... };`
  `export const SPREAD = { keys: { '<key>': { '<region>.<metric>': sd } }, emd: {...}, parity: { '<id>': sd } };`
  (sd rounded to 5 decimals; SPREAD keeps every sd, not only the noisy ones). `node --check` must pass on the text.
- `PROOF_TARGETS` (PLAN section 2 :60-74; one array per Fn, each `{ key, metric, bad: 'high' | 'low' }`, `bad` = the
  side the bad build sits on):
  - F1: `so-s1-goods-in@epic`, `so-s1-girder@epic`: `upper.veil` high, `upper.contrast` low, `whole.mean` high.
  - F2: `so-s1-goods-in@epic`, `so-s1-goods-in@low`: `floor.nearBlack` high, `floor.mean` low.
  - F4: `so-s1-workshop@epic`: `wall.arc` high; `so-s1-workshop@low`: `wall.arc` high.
  - F5: `so-door-on@low`, `so-door-on@epic`, `cp-door-on@low`, `cp-door-on@epic`: `leak.mean` high, `leak.p95` high.
  - F5b: `so-corner-on@epic`, `so-corner-on@low`: `leak.mean` high, `leak.p95` high; control `so-door-on@epic`,
    `so-door-on@low` (same metrics; expected green).
  - F6: every `m-*` view at `@epic` and `@low`: `whole.mean` low, `whole.nearBlack` high.
  - F7: `m-a3-lobby@low`: `wall.blotch` high, `wall.arc` high; `m-a3-lobby@epic` the same (reference).
  - F8: `cp-s2-b@epic`, `cp-s2-d@epic`, `cp-s3-a@epic`: `upper.veil` high, `upper.contrast` low, `whole.mean` high.
  The F6 view list comes from `viewpoints.mjs` at call time (the CLI passes `items`), not a literal list.
- `proofRows(fn, bad, fixed, { spread, tolerances, items }): ProofRow[]` with
  `ProofRow = { key, metric, bad: number | null, fixed: number | null, delta: number | null, sd: number | null, sep: number | null, dirOk: boolean | null, separates: boolean | null, mid: number | null, drift: boolean | null, rule: string | null, ruleBad: 'red' | 'green' | null, ruleFixed: 'red' | 'green' | null, note: string | null }`:
  `bad` / `fixed` read from the run's shot or rig record (`fixed` run may be null: F5b on master); `delta = bad -
  fixed`; `sd` = SPREAD of the same key and metric (null when absent: note `no sd`); `sep = |delta| / max(sd, 1e-4)`;
  `dirOk` = delta > 0 for `high`, < 0 for `low`; `separates = dirOk && sep >= K_SIGMA`; `mid` = sqrt(bad * fixed)
  when both > 0.001, else (bad + fixed) / 2 (PLAN :71 midpoint, VG8 decides); `drift` = whether `compare(key,
  stripThin(fixed metrics), stripThin(bad metrics), tolFor(key, tolerances))` returns a flag on that region and metric
  (a regression from fixed to bad would flag against a fixed baseline); `rule` = the item's calibrated rule for that
  address and preset (`max 0.004`, `min 0.2`) or null; `ruleBad` / `ruleFixed` = red when the value breaks it. A
  missing value: the row stays with nulls and `note` = the reason (`error: ...`, `region skipped: small` from the
  record's `skips`, `not in run`).
- `parityFor(fn, run, items): ParityRow[]` - the run's parity rows whose `view` is one of the Fn's view ids (F6: all
  `m-*`, F1 / F2 / F4: the `so-s1-*` views, else none).
- `renderProof(rows, parity, { fn, badLabel, fixedLabel }): string` - markdown: a title line, the rows table
  `| key | metric | <badLabel> | <fixedLabel> | delta | sd | sep | dir | separates | mid | drift | rule | rule bad | rule fixed | note |`
  (4 decimals, sep 1 decimal, '-' for null), then the parity rows of both runs
  `| run | id | level | luma | range | meter | field | ok | skip | note |`, then one summary line
  `F<n>: <s>/<t> rows separate, <d> drift, rule red on bad <rb>, green on fixed <gf>`.

## noise.mjs (CLI; `main()` only when run directly)
- `node scripts/visual-gate/noise.mjs spread <run1.json> <run2.json> <run3.json> [--out scripts/visual-gate/tolerances.mjs] [--md <file>]`
  - reads the files, refuses (exit 1) runs whose renderer or sha differ, or fewer than 2 runs; prints: runs (sha8,
  version, verdict, wall s, notRun count, errors count), keys measured / missing, `selfCompare` counts (floors vs
  tolerances, the first 20 of each), `noisy` lines; `--out` writes `renderTolerances` (source = run sha, version,
  renderer, runs n, `at` = now); `--md` writes the same printout as markdown (phase 2 pastes it into VG7.md).
- `node scripts/visual-gate/noise.mjs proof --fn F1..F8|F5b --bad <result.json> [--fixed <result.json>] [--bad-label x] [--fixed-label y]`
  - loads `viewpoints.mjs` (items) and `tolerances.mjs` (`TOLERANCES`, `SPREAD`; absent -> floors and `sd` null with
  a printed WARN), prints `renderProof`. Exit 0 (a report); usage errors exit 2.

## push-results.mjs (CLI + export)
`node scripts/visual-gate/push-results.mjs --dir <folder> --branch shots/visual-gate-<name> --prefix <p> [--message <text>] [--dry-run]`
- exported `pushFolder({ dir, branch, prefix, message, dryRun = false, cwd = process.cwd(), remote = 'origin' })`:
  refuse (throw) a branch not matching `^shots/visual-gate-[a-z0-9.-]+$`, a prefix with `..` / a leading `/`, a
  missing or empty dir, any file over 50 MB or a total over 150 MB. Every file under `dir` (recursive, sorted) goes to
  `<prefix>/<relative path with />`. Plumbing as `store.mjs` `writeFiles` (copy it, do not import or edit store.mjs):
  soft fetch `+refs/heads/<branch>:refs/remotes/<remote>/<branch>`; a temp index in `os.tmpdir()` (removed in
  `finally`); `read-tree` of the remote-tracking ref when it exists (files already there stay; same paths are
  replaced); `hash-object -w` per file (Buffer through `--stdin`); `update-index --add --cacheinfo`; `write-tree`;
  `commit-tree` with that ref as parent, or orphan the first time; push `<commit>:refs/heads/<branch>` with 5 tries
  (refetch + rebuild between); returns `{ commit, files, bytes }`. When `git config user.name` is empty, the commit
  gets `GIT_AUTHOR_* / GIT_COMMITTER_*` = `visual-gate (laptop)` / `visual-gate@localhost`. `--message` default:
  `visual-gate results <prefix> (<files> files)`. `dryRun`: build the commit, print it and the paths, push nothing.
  HEAD, the index and the working tree of `cwd` are never touched. git via `execFileSync('git', args, { cwd,
  windowsHide: true, timeout: 120_000 })`.
- CLI prints `pushed <files> files (<MB> MB) to <branch> <commit8> under <prefix>/`; exit 0 ok, 1 error, 2 usage.
  It runs on the laptop inside an alone step (cmd.exe), so no shell features: plain arguments, no spaces needed.

## VG7.md (the noise report; VG8, P1-P7 and the train read it)
- Header: master sha / version, renderer, chrome, the request id, the 3 runs (verdict, wall s, low / epic browser s,
  warnings count, parity misses, KNOWN lines), and whether run 3 was recorded.
- Runtime: the three wall times against the 180 s target / 300 s cap (PLAN 7, M0.md): mean and max.
- Spread: keys measured / missing (with why); the 20 largest sd per STATS field (key, region, sd, mean); emd sigma
  max; leak sd per rig key; card luma sd and meter d sd per id.
- Tolerances: how many keys got a field above floor, per field the count and the max value; the `noisy` lines
  (findings for VG8, e.g. a region unstable from TAAU or converge, or a leak / parity rule tighter than 4 sd).
