## Choices
- `gearHit` head + helmet always staggers (the knock-off is its own event); body + armour staggers only when `sinceStagger >= staggerCd` (the edge counts).
- `sweepPoints`: a point exactly `thin` m from a kept point is kept (drop only when strictly closer). Ties in the nearest-first order keep gather order (insertion sort, stable). It allocates temporary arrays: load time only.
- `sweepPoints` takes plain point lists. A caller passes `routes.map(r => r.points)`; `PatrolRoute.points` is `Pt[]` = `[number, number][]`, which fits.
- `responseTeam` floors a fractional `perStage`; NaN stage or `perStage` = no team. `out` is typed `EnemyKind[]` (`enemyDefs.ts`).
- `stageGear` floors fractional stages, clamps to 0..3, NaN and negatives = 0.
- `GuardSlot` (the validator's slot shape) gained optional `gear` and `kind` so a `SquadSlot` / `SectorGuard` still satisfies it.
