## The gap (origin/train/31 e383ba16)
After combat, every searcher walks the same blind spiral round the one last known position: `Enemy.decide`'s search
branch (`src/ai/enemy.ts:2174-2190`) takes `ringPoint(cx, cz, searchK - 1, ctx.searchSlot(this), spec)`
(`src/ai/response.ts:99-105`: golden-angle bearings, radius 2 m + 2.5 m per point to 11 m), snapped to the nearest
walkable cell within 4 cells (`:2183`). The points know nothing of the level:
- a point behind a wall snaps into the next room, so a searcher walks a long way round through doors to look at a spot
  the player could not have reached (or the point is unreachable and skipped, `:2217-2221`, S6 polish 6);
- the spiral ignores where a person can hide: dark cells and cover beside the last known position are visited only by
  chance; lit open floor gets the same look;
- searchers split only by bearing (`searchSlot` `enemyManager.ts:558-562` = a count of lower-numbered searchers), so
  two can look at the same corner while another stays unchecked.
S24 gives each intruder his own last known position and a nav flow field (`flowOf(slot)`): the path distance from that
position to every cell, already computed. S25 uses it.

## Goal / done looks like
- A player who breaks contact and crouches in a dark corner 6 m from where he was last seen is checked early by one
  searcher, who walks there by the nav and looks into it; lit open floor and the room behind a wall come later or never.
- Three searchers cover three different spots, not one corner twice.
- A spot farther by path than the player could have gone in the time since he was seen is not searched first.
- Calm searches (a body S18, a device S17, a call, a pair, a lure) keep their ring: unchanged.

## Data shapes
```ts
// src/ai/searchArea.ts (new, pure, no Babylon)
/** The probable area: cells reachable from the last known position within R = clamp(base + speed x seconds since he
 *  was seen, base, max) path metres. Points: cover spots and dark cells in it, best first, spaced >= `spacing` m, at
 *  most `points`; dark = baked light below `dark` at `sampleY` m over the floor (the light perception reads, parity).
 *  `enabled` false: today's ring for every search. */
export const SEARCH_AREA = { enabled: true, base: 6, speed: 1.5, max: 20, points: 12, spacing: 3, lattice: 2,
  dark: 0.28 /* LIGHT.shadow */, sampleY: 0.9, wDark: 1, wCover: 0.6, wNear: 0.8, rebuild: 2 } as const;
export class SearchPlan {             // one per intruder slot, made once at load
  readonly x = new Float32Array(SEARCH_AREA.points); readonly z = ...; readonly score = ...;
  /** Guard num that claimed point k (-1 free), done flags. */
  readonly claim = new Int32Array(SEARCH_AREA.points).fill(-1); readonly done = new Uint8Array(SEARCH_AREA.points);
  n = 0; cx = 0; cz = 0; builtAt = -1;
  /** Candidate in, kept only if it beats the worst and is >= spacing from every kept point (insertion, no alloc). */
  offer(x: number, z: number, score: number): void;
  /** Best free point for a searcher at (gx, gz): max score - wNear * dist / R; claims it for `num`; -1 none left. */
  take(num: number, gx: number, gz: number, r: number): number;
  release(num: number): void;  finish(k: number): void;  reset(cx: number, cz: number, now: number): void;
}
export function areaRadius(sinceSeen: number): number;   // clamp(base + speed * t, base, max)
export function pointScore(light: number, cover: boolean, pathM: number, r: number): number;
```

## Build
1. `src/ai/searchArea.ts` as above (pure, unit-tested, no allocation after construction).
2. `EnemyManager` (`src/ai/enemyManager.ts`):
   - `plans: SearchPlan[]` (one per `MAX_INTRUDERS` slot, built in the constructor).
   - `buildPlan(slot)`: when a guard hunting `slot` starts a combat search and the plan is older than
     `SEARCH_AREA.rebuild` s or its centre moved > 1 m: `r = areaRadius(intruders.seenT[slot])`; `field =
     flowOf(slot)` (path distance in cells, x `nav.cell` for metres); candidates (a) the level cover in range,
     `coverGrid.query(x, z, r, scratch)` (`coverGrid.ts:117`, an `Int32Array` scratch made once), kept where the
     cover's nav cell has `field * cell <= r`, at the cover's own position; (b) a lattice every `SEARCH_AREA.lattice` m
     over the square of half-side `r` round the centre (at most 21 x 21), each walkable cell with `field * cell <= r`
     whose baked light `world.lightField.levelAt(x, y + sampleY, z)` (`lightField.ts:171`; torches are dynamic and
     excluded on purpose) is below `dark`; each offered with `pointScore`. No ray, no A*.
   - two `AiContext` hooks (declare in `AiContext`, `src/ai/enemy.ts:102-170`): `searchPoint?(e: Enemy, out: P2):
     boolean` (`buildPlan` if due, then `plans[e.hunt].take(e.num, ...)`; false = none left, or no plan) and
     `searchDone?(e: Enemy, reached: boolean): void` (marks his claimed point done; unreached: done too, so nobody
     retries an unreachable one).
   - release a guard's claim on death, knockout, despawn, leaving searching, and `clear` / `resetMemory`.
3. `Enemy.decide`, the search branch (`src/ai/enemy.ts:2174-2190`): when `lvl === 'searching' && this.combatSearch &&
   !this.searchOwn && this.hunt >= 0 && SEARCH_AREA.enabled`, the first point stays the last known position itself
   (`searchK === 0`, as today); from then on `ctx.searchPoint(this, this.spot)`; it returns false -> today's
   `ringPoint` line as the fallback. Everything after (`nearestWalkable` snap, room / leash clamps `:2192-2198`, pace,
   rush, the look) is unchanged.
   - the look ends (`:2208-2211`) and the unreachable skip (`:2217-2221`): call `ctx.searchDone(this, reached)` before
     `searchK++` when the point came from the plan (a private `planPoint` flag).
   - the arrival facing is the walk's, so the look sweep (`:2213`) and his torch (`updateTorches` follows facing) go
     into the spot he walked to; no torch rule change.
4. Docs: `docs/systems/ai.md` (search after combat: the probable area, the plan per intruder, the fallback), `TESTING.md`
   (break contact, crouch in the dark corner near where you were seen: the first searcher comes to it; hide farther,
   in light behind a wall: they search the near dark first), `changes/feature-guard-ai-s25.md`.

## Allocation and cost
`buildPlan` is not per frame: at most once per intruder per `rebuild` 2 s, and only while someone searches for him.
Work: one cover query (tens of points) plus at most 441 lattice samples (a flow-field read and a baked-light grid read
each); no rays, no A*, no allocation (plan arrays and the query scratch are made once). Per-guard cost per point: one
`take` (12 points). `hyp2` only.
