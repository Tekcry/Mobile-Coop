## The AI API (for the game side)
```ts
// src/ai/consoleFault.ts
export interface ConsoleHost { reset(id: string): boolean } // turn console `id` back on through its own toggle path
// src/ai/enemyManager.ts
em.consoleHost: ConsoleHost | null;                            // set by the mode, null on dispose
em.consoleState(id: string, x: number, y: number, z: number, on: boolean): void;
//   every toggle: the player's press (off), a loop running out (on), a guard's reset (on). y = the floor the console
//   stands on (Marlow's console devices have y 0: the floor); the guards look at y + 1.1 m.
em.watchesConsole(e: Enemy, x: number, y: number, z: number): boolean;
//   is guard `e` watching the console now (calm, free, the screens in view with a clear line)? For the refusal.
em.consoleResets / em.consoleFinds / em.consoleTable           // counters and numbers (tests / e2e)
```
Behaviour: a switch-off seen at once (a calm, free guard with the screens in view) is noticed now; else the next such
guard who looks at it notices it (a guard drawn off by a distraction once he is back). One walker (nearest by path) says
"Console's dropped out again...", walks at patrol pace, works it `BREAKER.resetT` 2 s, `consoleHost.reset(id)`, back to
his post calm. A second cut noticed within `BREAKER.repeatT` 60 s: the S2 light check at the console (1-2, the ring, the
radio, "Console's off again. Someone's been at it."), then, once the check is over, the reset walk. Turned back on by
other means (the loop ran out), the walk ends.

  /** (guard-ai S22, G6) A guard turned console gate `gateId` back on: as its loop running out (the flag clears, the

    const g = this.gateRt(gateId);

    return true;

```ts
  /** (guard-ai S22, G6) A console's flag set (its cameras looped: off) or cleared (on): the guards hear of the toggle. */
  private consoleEdge(flag: string, on: boolean): void {
    const lay = this.layout;
    const em = this.g.enemyMgr;
    if (!lay?.consoles || !em) return;
    for (const c of lay.consoles) {
      if (c.flag !== flag) continue;
      const dv = lay.devices[c.id];
      if (dv) em.consoleState(c.id, dv.x, dv.y, dv.z, on);
    }
  }

  /** (guard-ai S22, G6) A guard worked console `id`: its loop ends (`CourseState.consoleBack`); the next `handle` sends
   *  `flagCleared` on (the guards, the cameras, the client). Not reentrant: no `handle` from inside the guards' update. */
  private consoleBack(id: string): boolean {
    const gid = this.consoleGate.get(id);
    if (gid === undefined || !this.state?.consoleBack(gid)) return false;
    this.dirty = true;
    return true;
  }
```
   - `dispose()`: add `if (this.g.enemyMgr) this.g.enemyMgr.consoleHost = null;`
