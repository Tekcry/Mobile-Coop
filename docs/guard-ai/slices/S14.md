## Choices
- Alert calls carry their own negative incident id (A70). The WIP used the board's incident for the radio check's call:
  the S2 pair lead also radios `missing` on that id at the same moment (`Enemy.pairSearch`), and the radio queue
  dedupes receivers by (guard, incident, kind) keeping the first call's caller, so the alert would have been lost
  whenever the lead completed first (lower call id, tie on due time). Own ids keep the two apart; the lead's report
  stays an ack. Covered by a radioNet test and the wiring tests.
- One `missing` call per radio check, not per missed member (A71); the S10 miss calls even with the partner's guard gone.
- Shots: one call per open call (A72); the caller is the nearest calm hearer, tier 3 hearers (sent to combat, they
  call contact) excluded. The pair on delivery reuses the board (A73).
- Removed the WIP's unused `Awareness.timedHoldMask`; moved `unitWord` into `barks.ts` (no barks -> sectionAlert import).
- `mayCallShots` reads `!(e.blindT > 0)` so a stand-in without the field does not count as blinded.
