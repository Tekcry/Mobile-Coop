## Data shapes
```ts
// src/ai/intruders.ts (new, pure, no Babylon)
import { MAX_INTRUDERS } from './targetPick';
/** `split` false: every report writes slot 0 (today's one shared position). `forget`: s after the last sighting with
 *  nobody hunting that intruder. `noFeet` (A148): no position for his intruder = no walk to the real feet. */
export const INTRUDERS = { split: true, forget: 2, noFeet: true } as const;
export class IntruderBoard {
  readonly x = new Float32Array(MAX_INTRUDERS); readonly y = ...; readonly z = ...;
  readonly valid = new Uint8Array(MAX_INTRUDERS);
  /** Seconds since slot i was last seen (99 = never). */
  readonly seenT = new Float32Array(MAX_INTRUDERS).fill(99);
  /** Player id per slot ('' = free): stable when the players list reorders (a rejoin, coop4). */
  private readonly ids: string[] = ['', '', '', ''];
  /** The slot most recently reported (the solo mirror and the response teams), -1 none. */
  freshest = -1;
  slotFor(id: string): number;           // linear compare over 4 ids, assigns a free slot; no allocation
  report(slot: number, x: number, y: number, z: number, seen: boolean): void;  // seen: seenT = 0
  forget(slot: number): void;
  step(dt: number): void;                // seenT += dt
  clear(): void;                         // ids kept (same players), positions dropped
}
```
`EnemyManager`: `readonly intruders = new IntruderBoard()`; `lkp` stays a `Vector3` and `lkpValid` / `sightT` stay
fields, **mirrored** from `intruders.freshest` after every report / forget (so `scripts/e2e-sectorops.mjs`,
`scripts/e2e-stealth-ai.mjs`, `scripts/guard-cap.mjs`, the 8 test files that read them and `sweepTeam` keep working).
New: `lkpOf(slot): Vector3 | null` (a reused `Vector3` per slot, never a new one), `huntingOf(slot): boolean`,
`flowOf(slot): Float32Array`. `Enemy`: `hunt = -1` (the intruder slot he is engaged on), public read.

## Allocation and cost
No allocation per tick: typed arrays sized `MAX_INTRUDERS`, the reused role buffers, reused `Vector3` per slot, index
loops, `hyp2` / `hyp3`. Flow fields: the expensive part (multi-source Dijkstra over the nav grid). Today one rebuild per
0.5 s whether or not the position moved; after S24 a rebuild only on a move or a nav change, one per update at most,
so solo costs less than today and two intruders cost at most one rebuild per tick. Roles: two passes at 2 Hz when two
fights run.
