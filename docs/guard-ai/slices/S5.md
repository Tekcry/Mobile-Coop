## Built
- `EnemyManager.placeSlot(e, slot, section?)`: post (`slot.post`, leash round the spawn point, facing `slot.yaw`),
  profile, section (Sector Ops passes the `SectorDef` index; omitted = the `MapLayout.guardAi` zone he stands in, else 0).
  Called in `sectorMode.fill` (`this.run.index`), `courseMode.spawnSquad` and `infiltrationMode.fill` (one line each).
- `Enemy` post block: `postDef`, `postYaw`, `section`, `profile`, `secure` (high security), `inLeash`, `setPost`,
  `lureTo`, `lurePhase` / `lureLook` (e2e), private `lureStep`, `leashed`.
- Board respects `mayLeave`: new view flag `GV_POSTED` (incidents.ts) set for a high-security post; `free()` skips him,
  so no investigation, light check, `callR` fallback or missing pair ever sends him. A normal post is sent like anyone.
- Distraction: in `hear` (noise / lure), `noise` (gunfire) at tier 2, and `lightsOut` (he saw it go), a high-security
  post gets `lureTo` instead of being a perceiver -> `PostLure`: walk to the leash point nearest the lure at the
  investigate pace, look 5 s sweeping +-0.6 rad round the lure bearing, walk back, face the post yaw 0.8 s, then the
  walker (rejoined). Tier 1: he only turns, as anyone. A second lure at the same leash point (< 1 m) does not restart
  him. The lure counts as `turning` in the alert input (the linger rule never walks him off) and gives only a turn's
  meter floor (<= `HEARING.turnMax`; a light: `PERCEPTION.suspicious` + 0.02). A sighting, a search or combat cancels it.
- Never outside the leash: investigate / search spots (bodies, radio checks, post-combat search) clamped into the
  leash; no revive of a body outside it (+1 m); `assignAlarm` skips a panel outside it (+1 m); combat: `chasePoint`
  clamped (link waypoints inside the leash kept), strafe point clamped, cover outside skipped in `pickCover` /
  `pickAdvance`, a last known position more than 1.5 m outside the leash is held from the post (the `hold` branch).
- Map data: `EnemyManager.mapNoisy` = `MapLayout.guardAi.noisy` (the masking from the start); Sector Ops sets the live
  section's `SectorDef.noisy` on load (else the map's). Load checks in dev: `validateGuardAi` on the map layout
  (constructor), `validatePosts` per Sector section (`loadSection`), via the new `reportGuardAi` (console warnings,
  never a throw).

## Note for the map teams (Course Ready, Menu Notes)
- Put `post` on the guard's slot (`SquadSlot` / `SectorGuard`): `post: { leash: 3, highSecurity: true, guards: 'token' }`.
  The leash centre is the slot's x, z; the post facing is the slot's `yaw`. `leash: 0` = he stands on the spot (turns
  only). Otherwise a leash is >= 0.5.
- Size the leash so that its edge nearest your lure spot is off the choke: a lured guard stands at the leash point
  nearest the lure and faces it (+-0.6 rad) for >= 5 s, then walks back (A12). Lures that work: a noise or thrown item
  inside half its reach of him, gunfire likewise, a light he sees go out (in view, or the room he stands in).
- A high-security post must not be `free`, and every `route` point stays inside his leash (validator errors).
- No `highSecurity`: a normal post; the board sends him anywhere like any guard and he walks back after.
- Sector Ops: nothing to call; `sectorMode` places every guard with the section index. Course / other maps: the spawn
  code calls `em.placeSlot(e, slot)` after `spawn` / `setPatrol` (done in courseMode.spawnSquad and infiltrationMode).
- `noisy` on `SectorDef` (or `MapLayout.guardAi.noisy`): `{ id, x, z, y?, radius 1..20, db 0..30 }`; 6 dB halves a
  listener's hearing reach, 12 dB quarters it.
- Run `validatePosts(section.guards, section.id)` / `validateGuardAi(layout, slots, { bounds, sections, section })` in
  your map tests; `tests/postsWiring.test.ts` already checks every live map's sectors (keys <= 32 per section, posts,
  noisy, entries).
- Marlow's training guard: `post: { leash: 0 }` is fine (passive guards ignore lures).

## Polish (not blocking)
- `POST.returnFace` 0.8 s is shorter than the calm turn needs for a big turn back; the walker finishes it.
- The lure walk uses the investigate pace; the sweep's peak turn rate (1.26 rad/s) is above the calm turn (1.05 rad/s),
  so the actual sweep is a little narrower than +-0.6.
- A lured guard says only the "suspicious" bark (from the meter); no own line yet ("Hm, what was that?").
