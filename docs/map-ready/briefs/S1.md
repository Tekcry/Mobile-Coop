## Interfaces (PLAN S1, written out; S2, S4, S9, S10 fill the fields S1 leaves at their defaults)
```ts
// src/core/mapReadyStats.ts - pure: no Babylon, no DOM import (window is touched only in gameState.ts)
export type BakeSource = 'shipped' | 'cache' | 'baked' | 'unknown';
export const AFTER_WINDOW_MS = 10_000;
/** Load counters other slices bump (S9: textures and files, S10: effects); the record copies their deltas at the reveal. */
export const loadCounters = { texReused: 0, texDecoded: 0, filesReused: 0, filesFetched: 0, effReused: 0, effCompiled: 0 };
export interface AfterWindow {
  done: boolean;
  /** Shader programs created in the window (`_compiledEffects` count delta). */
  programs: number;
  /** Frames whose program count changed (the spike log's `shaders` tag). */
  shaderFrames: number;
  /** Lamps landed and atlas tile uploads in the window (`BakedLamps.landings`, `.tileUploads` deltas). */
  landings: number;
  tileUploads: number;
  /** Materials added to the scene in the window. */
  materials: number;
  /** Body / weapon / guard mesh swaps seen in the window (`FrameSample.popIns` delta). */
  popIns: number;
  frames: number;
  p50: number; p95: number; max: number; // frame interval ms
}
export interface MapReadyRecord {
  map: string; mode: string;
  /** `flags.mapReady` at the load (S1 passes false; S2 passes the flag). */
  gated: boolean;
  /** Step name -> ms from the load start. S1 writes 'world' (World.create done) and 'create' (create resolved). */
  steps: Record<string, number>;
  /** ms from the load start to the reveal; -1 until it happens. */
  revealMs: number;
  /** True from the reveal on (S2's e2e helper waits for it). */
  released: boolean;
  /** S2: the cap cut the gate, and the step it was on. S1: false / ''. */
  capHit: boolean; capStep: string;
  bakeSource: BakeSource;
  /** The light bake's own ms (`LightBake.ms`), -1 without lamps. */
  bakeMs: number;
  /** Programs compiled between the load start and the reveal. */
  loadPrograms: number;
  /** `loadCounters` deltas over the load (0 until S9 / S10 bump them). */
  texReused: number; texDecoded: number; filesReused: number; filesFetched: number; effReused: number; effCompiled: number;
  /** `performance.memory.usedJSHeapSize` at the reveal in MB, -1 when the browser has none. */
  heapMb: number;
  after: AfterWindow;
}
/** Cumulative counters read once per rendered frame (the stats take the deltas). */
export interface FrameSample { programs: number; landings: number; tileUploads: number; materials: number; popIns: number }
export class MapReadyStats {
  readonly record: MapReadyRecord;
  constructor(map: string, mode: string, gated: boolean, now: number);
  step(name: string, now: number): void;
  setBake(source: BakeSource, ms: number): void;
  /** At the reveal: the frame sample then becomes the window's zero point. */
  reveal(now: number, s: Readonly<FrameSample>, heapMb: number): void;
  /** Every rendered frame; no allocation (a preallocated Float32Array of 2400 frame intervals). */
  frame(now: number, s: Readonly<FrameSample>): void;
  /** One line for `feedbackContext()`, e.g. "campusOps reveal 8.4 s, after 10 s: 0 programs, 3 landings, 0 pop-ins, p95 18 ms, bake cache". */
  summary(): string;
}
export function bakeSourceOf(declared: BakeSource | undefined, sectionBakeMap: boolean, sectionsRunning: boolean): BakeSource;
```
`bakeSourceOf`: `declared` wins when given (S4 adds `LightBake.source`); else a section-bake map (campusOps) reads
`baked` when its `SectionBaker` exists (it only exists on a cache miss, `world/lightBake.ts:104-111`) and `cache`
when not; any other map `unknown` (its full bake does not say hit or miss until S4).

## Steps
1. `src/core/mapReadyStats.ts` with the interfaces above. `frame()` before `reveal()` ignores the sample (load frames
   are not the window). After `reveal`, each `frame` adds `now - last` to the interval buffer and recomputes nothing;
   when `now - revealAt >= AFTER_WINDOW_MS` it fills the window's counts from the sample deltas, sorts a copy of the
   used part of the buffer once (allowed: once per match), writes p50 / p95 / max and sets `done`; later frames are
   ignored. `reveal` copies the `loadCounters` deltas taken since the constructor (the constructor snapshots them).
2. `tests/mapReadyStats.test.ts`: steps and reveal in ms from the start; window deltas from cumulative samples (a sample
   at the reveal of programs 40 and one at +10.1 s of 42 gives `programs` 2); `shaderFrames` counts frames whose
   `programs` changed; frames before the reveal ignored; frames after `done` ignored; p50 / p95 / max of a known series;
   `loadCounters` deltas; `bakeSourceOf` all four branches; `summary()` contains the map and the reveal seconds.
   `npx vitest run tests/mapReadyStats.test.ts --maxWorkers=2`.
3. `src/world/bakedLamps.ts`: add `landings = 0;` beside `tileUploads` (:266) and increment it by one per lamp marked
   landed in `landed()` (:741; after `have[i] = 1`, :749); add `rescans = 0;` and increment it where `frame()` re-scans
   new materials (:491-495, inside the `if`). Comments name map-ready S1. Nothing else.
