## Plan fixes (this brief's decisions; the lead logs them in STATE)
1. Cache folder name: a lamp key holds `:` (`lightBake.ts:95`), not a valid Windows folder name. The folder is
   `.prebake-cache/<h>/` with `h = fnv(key)` in base 36 (`voxel/lightShapes.ts` `fnv`); the manifest keeps the full key.
2. Stale manifest: `bakes/campusOps.json` has a fixed name, so a cache-first worker rule would serve an old manifest
   after a deploy (its key then never matches: every load bakes on the PC). Section files carry `h` in their names
   (`campusOps-<h>-s<k>.bin.gz`, cache-first is then safe) and the manifest gets its own network-first rule.
3. Parallel by lamp, not by section: one vitest file per section makes campus S1 (88.6 s single thread, research row 6)
   the wall time. The prebake shards the lamps over a fixed set of shard files instead; the per-section output files
   are written after the join.
4. A server may answer a `.gz` with `Content-Encoding: gzip` (the browser then hands over plain bytes): the reader
   checks the gzip magic (`1f 8b`) and only then decompresses.
5. `markPlaying` (step 6): `complete()` already saves when the match is not playing (`sectionJobs.ts:440-441`), so
   with S2's `bake-all` wait the write happens in the hold; S4's change is one explicit `saveIfDue()` in `markPlaying`.

```ts
/** A16: the seed left both keys (same bytes for every seed: shapes + lights are hashed). Used by the game and the prebake. */
export function lampKeyOf(mapId: string, shapesHash: string, lights: Float32Array): string; // `lamps:${mapId}:v${LAMP_VERSION}:c${CANON_VERSION}:${shapesHash}:${hashFloats(lights)}`
export function moonKeyOf(mapId: string, shapesHash: string, dir: readonly [number, number, number]): string; // `moon:${mapId}:v${MOON_VERSION}:c${CANON_VERSION}:${shapesHash}:${dir.map((v) => v.toFixed(4)).join(',')}`
export interface LightBake { /* ...as today... */ source: 'shipped' | 'cache' | 'baked' | 'none' }
// src/world/shippedBake.ts
export interface ShippedManifest { map: string; key: string; lampVersion: number; canonVersion: number; lamps: number;
  files: { name: string; bytes: number; sha256: string; lampIds: number[] }[] }
export function packLamps(ids: readonly number[], parts: readonly LampResult[]): Uint8Array;   // little-endian, magic + format version, 4-byte aligned arrays
export function unpackLamps(bytes: Uint8Array): { ids: Int32Array; parts: LampResult[] } | null; // null on a bad magic / version / length
export function joinShipped(lights: Float32Array, lo: readonly number[], hi: readonly number[], ids: Int32Array, parts: readonly LampResult[]): LampResult | null;
export async function readShippedLamps(o: { mapId: string; key: string; lights: Float32Array; lo: [number, number, number];
  hi: [number, number, number]; base?: string; fetchFn?: typeof fetch }): Promise<LampResult | null>;
```
`joinShipped` does exactly what the section baker's landing does (`voxel/sectionJobs.ts:382-392`: each lamp's `vis` at
`lampLayout(...).at[i]`, its bounce part `{ box, data, bits }` or null) and `joinBounce` (`world/sectionBake.ts:113`),
giving `{ kind: 'lamps', id: 0, boxes, vis, bounce }`; every lamp must be present once, else null.

## Steps
1. Key (A16, live, not flagged): in `lightBake.ts` replace the inline keys (:91 moon, :95 lamps) with `moonKeyOf` /
   `lampKeyOf` (no seed); keep `LightBakeInput.seed` (callers pass it; unused by the keys now). Add
   `source` to `LightBake` and set it: `none` without lamps, `cache` on a `readLampCache` hit (:105-107), `baked` when
   a `SectionBaker` starts (:108-111) or on the full path's miss (for the full path read the cache first in `lampJob`
   and call `bakeLevelLamps` only on a miss, so the source is known; its own second read on a miss is a cheap miss).
   Tests (step 7) first for the key: two seeds -> one key; a moved lamp -> a new key.
2. Format: `packLamps` / `unpackLamps` / `joinShipped` in `shippedBake.ts` (pure, no Babylon, no DOM). Layout: magic
   `NSLB`, u32 format 1, u32 lamp count, per lamp u32 id, `BOX_STRIDE` f32 box, u32 vis length, `BOUNCE_BOX_STRIDE` i32
   bounce box, u32 bounce length; then every vis, every bounce `data`, every bounce `bits` (u16, 2-byte aligned).
3. Prebake (Node, no new package; the `scripts/light-measure/vitest.probe.config.ts` pattern):
   - `scripts/prebake.mjs`: `PREBAKE=0` -> print "prebake skipped" and exit 0 (the build then ships no bake; the PC
     bakes as today). Else runs `npx vitest run --config scripts/prebake/vitest.prebake.config.ts <files>` in phases:
     (a) `plan.prebake.ts`: builds campusOps in Node the way `World.create` does (`world/world.ts:176-185`:
     `new LevelBuilder()`, `campusOps.build(b, 1)`, `applyMapFlicker(b.lights, 'campusOps', 1)`,
     `applyMapSway(b, 'campusOps')`, then `b.prepare('campusOps', { dressing: dressingOn(campusOps) })`,
     `world/levelBuilder.ts:587`; the light set ignores `detail`), `bakedLights(b.lights)`, the key `lampKeyOf`, and
     writes `.prebake-cache/plan.json` (key, `h`, lamp count, lo / hi); if `.prebake-cache/<h>/campusOps.json` exists,
     stop: nothing to bake. (b) shard files `shard-0.prebake.ts` ... `shard-7.prebake.ts` (one line each, calling a
     shared `bakeShard(i, 8)`): lamp `j` with `j % 8 === i`, each baked alone as the workers do
     (`bakeLamps({ kind: 'lamps', id: j, shapes, lights: L.slice(j * LAMP_STRIDE, (j + 1) * LAMP_STRIDE), lo, hi })`,
     `voxel/sectionJobs.ts:373`), written with `packLamps` to `.prebake-cache/<h>/shard-<i>.bin`. Pool:
     `maxWorkers` from `PREBAKE_THREADS`, default `Math.max(1, Math.min(4, cpus - 1))` (desktop CPU target);
     `testTimeout` 1 800 000. (c) `join.prebake.ts`: reads the shards, groups lamps into per-section files by the
     lowest set bit of `lampSectionMasks(L, CAMPUS_BAKE)` (`world/sectionBake.ts`; mask 0 -> file `s<sections>`),
     writes `campusOps-<h>-s<k>.bin.gz` (Node `zlib.gzipSync`, level 9) and `campusOps.json` (the manifest above with
     sha256 of each `.gz`), deletes the shard files, checks the caps (16 MB a file, 48 MB the map, compressed: over
     -> print every size and exit 1), writes `.prebake-cache/current.json` (`{ h, files }`) and removes every other
     `<h>` folder (prune).
   - Logs one line: `prebake campusOps: <n> lamps, <files> files, <MB> MB gz, <s> s` (CI and desktop seconds go into
     the report).
   - `package.json:10`: `"build": "node scripts/prebake.mjs && npm run typecheck && vite build"`. `.gitignore`: one
     line `.prebake-cache` under the `.music-cache` block.
   - STOP here if the caps fail on the first real run: report the sizes to the lead and build nothing further (PLAN S4
     "Order": the planner re-plans, a new BRIEF A-line, a fresh plan checker). A lossless repack is allowed; never a
     lossy one (A15 parity).
