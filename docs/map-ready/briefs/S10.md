## Interfaces (PLAN S10, written out)
```ts
// src/core/keptParts.ts (added beside S9's texture holder)
export const KEPT_EFFECTS = 400; // starting value (G10)
/** The shape of a Babylon Effect the holder needs (pure code stays Babylon-free). */
export interface KeptEffect { readonly name: unknown; isReady(): boolean; dispose(force?: boolean): void }
export class KeptParts {
  /** `app.releaseState` with the flag on, before the scene is disposed: one reference on every ready compiled effect
   *  (least recently used out past KEPT_EFFECTS), each stripped of what ties it to the old scene. */
  keepEffects(compiled: Record<string, KeptEffect>): void;
  /** GPU context lost: every kept effect is released (a stripped effect cannot rebuild itself). */
  dropEffects(): void;
  readonly stats: { /* S9's fields */ effReused: number; effCompiled: number; heldEffects: number };
}
```

## Steps
1. Plugin audit first (report table: plugin, file:line of `getCustomCode`, inputs, verdict). Every `getCustomCode`
   must depend only on its defines and module constants, so an equal cache key (shader name + defines,
   `Engines/thinEngine.pure.js:1683`; the plugin's main define is per class name, `materialPluginManager.pure.js:43-44`)
   always means equal code: `world/bakedLamps.ts` `LampPlugin` (class :1387, `getCustomCode` :1544; its interpolations

   declaration is code too). A per-map value found moves into a define or a uniform here (<= ~20 lines a plugin), or
   that plugin's materials are kept out of the budget (name them). Other effects (post processes, `ShaderMaterial`
   in `vfx/cameraCueView.ts:215`, the `Effect.ShadersStore` passes in `vfx/*.ts` and `world/surfaceAtlas.ts`) are keyed
   by their own code: in the budget.

   different map inputs (lamp counts, door lists, atlas sizes: whatever step 1 found it reads) give identical

4. `app.ts` `releaseState` (:364-377): with `kept.enabled`, after S9's `handOver` and before `prev.scene.dispose()`
   call `kept.keepEffects(engine._compiledEffects)`; then replace `this.engine.releaseEffects()` (:376) with releasing
