## Interfaces (PLAN S9, written out)
```ts
// src/core/keptParts.ts - the holder logic is pure (no Babylon import); Babylon objects reach it as the shape below
export interface KeptTex { incrementReferences(): void; dispose(): void; readonly width: number; readonly height: number }
export const KEPT_TEXTURE_MB = 256; // starting value (G10): GPU bytes estimated, see step 2
export class KeptParts {
  enabled: boolean;                                           // = flags.mapReady (App sets it)
  /** A texture made for `scene` under a stable key (figure.ts `texture()`): counted reused when the engine cache hit. */
  useTexture(scene: object, key: string, tex: KeptTex, reused: boolean, bytes: number): void;
  /** A model file a match read through `loadModel` (kit, props, campus art): counted reused when it was parsed already. */
  useFile(scene: object, url: string, reused: boolean): void;
  /** `app.releaseState`, before the scene is disposed: hold one reference on every kept texture this scene used, then
   *  drop what the last two hand-overs did not use, then the least recently used past the byte budget. */
  handOver(scene: object): void;
  /** GPU context lost, or the Textures setting changed: release every held texture. */
  dropTextures(): void;
  readonly stats: { texReused: number; texDecoded: number; filesReused: number; filesFetched: number; heldTextures: number; heldMb: number };
}
export const kept: KeptParts; // the one holder; `App.kept` points at it
```
`forgetFile`: a file not used in the last two hand-overs is dropped with `forgetModel(url)` (`figure.ts:184`); kit,
props and campus art files only (operator, weapon and shield files keep today's parse-once rule).

## Steps
1. `src/core/keptParts.ts` + `tests/keptParts.test.ts` (pure part first, fake `KeptTex` objects): a hand-over holds one
   reference per texture (once, not per hand-over); a texture unused in two consecutive hand-overs is disposed once;
   the byte budget drops the least recently used first; `dropTextures` disposes every held one once; `enabled` false:
   every call is a no-op (flag off = today); `stats` counts.
2. `figure.ts` `texture()` (:226-240): new last parameter `keep = true`. With `kept.enabled && keep`: key from the
   `WeakMap<GlbImage, string>`; create the texture with that key as its URL and the image bytes as its buffer
   (Babylon 9.29 `Texture` ctor: `buffer` arg; `texture.pure.js:308` asks `_getFromCache(url)` first,
   `baseTexture.pure.js:580-597` matches on url, mipmaps, sampling, invertY, sRGB, and increments its references);
   KTX2 keeps `forcedExtension` `.ktx2` and its mime; `reused` = the internal texture existed in

   internalTexture, reused, bytes)`; bytes = width x height x (KTX2 ? 1 : 4) x 4 / 3. If Babylon 9.29 cannot take a
   KTX2 buffer under a non-blob URL (read `Engines/abstractEngine*.js` / `thinEngine.pure.js` `createTexture` and the
