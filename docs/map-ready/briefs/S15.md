## The rule for every step
Same texels, same iterations, same math: only the form fxc sees changes. Behind `flags.mapReady` through one plugin
define `LAMP_NOUNROLL` (set in `LampPlugin.prepareDefines` and in the volume mix's `mixDefines` when the flag is on),
so flag off compiles today's text byte for byte and the lead can time both on one build. A step whose picture
differs from flag off by more than float noise on the GPU read-backs stops the slice (no look change without
Michael's sign-off, BRIEF "Sign-off needed").

   treatment only if its sampler has no mips (check each; list them in the report). Test: under the define no

   Commit, then the lead's laptop run (below). If the cold Epic body variant is now at most 8 s, skip step 3.
3. Only if step 2's run leaves the body variant over 8 s: trip counts the compiler cannot see. Under `LAMP_NOUNROLL`,
