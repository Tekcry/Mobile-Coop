## How it works
`warmShaders(app, { map, mode, loadout, preset }, signal)`: one small unrendered `Scene` on the app's engine (no
`World`, no Havok, no nav, no level meshes: Q3 option 1), holding only what decides the match's body, guard and
weapon shader keys: the figures (from S9's kept files, preloaded by S11), the map's light rig at that preset (the same
light count and shadow kinds the match's `lightRig.configure` makes), the scene features the match sets (fog,
environment texture, image processing) and a `LampPlugin` fed the map's lamp descriptor (the inputs of its
`prepareDefines`). Each warm mesh's material runs `forceCompilationAsync`; when they settle, `keptParts.keepEffects`
takes the ready effects (S10), then the warm scene is disposed. The match's `createEffect` then returns the kept
effect on the same key (S10's `effReused`).
