# CT prototype M1 - body logic (2026-10-18)

Prototype first (G4): every number is a starting value (G10). Posture (P1 item 5) is NOT in this slice: it waits for Wren.

## Built
- **Speeds (loco M20 Q8):** five analog speeds, the stick picks the speed (`AnalogGear` snapping, unchanged). Standing
  0.2 / 0.75 / 2.0 / 3.0 / 4.2 m/s, crouched 0.4 / 0.85 / 1.5 / 2.1 / 2.6 (`GEARS`). No sprint: `SprintGate`, the sprint
  stance, `sprintEdge`, `crouchToggleNext`, gear 6, the `dash` / `sprint` bindings (L3 and Left Shift) and `PF.sprint`
  are gone. The `dash` action id stays only for photo mode's fast pan and the ladder quick climb; nothing binds it. L3 is
  unbound (M3 puts back-to-wall there). The D-pad up / down (wheel, `=` / `-`) still steps the max-speed cap (spawn 3 =
  2.0 m/s standing); the HUD gear pips are removed (G107), no indicator.
- **Noise (G40):** `NOISE_QUIET` unchanged in value (crouch 1.7, stand 1.45) but now means standing speeds 1-2 and
  crouched speeds 1-3 silent; the rest rise (`noiseRadius(speed, crouched)`).
- **Starts:** `CT.startTime` 0.45 s (95% of the pace, any speed). The torso lean is the existing accel-driven lean.
- **Stops (G26, G27):** `CT.stopTime` 0.2 s: slide 0.29 m from 4.2 m/s, in the unit test <= 0.32 m. No closing step
  (`FootPlanner.closeStep` and `CLOSE_STEP` removed; a swing foot just sets down where it is). Releasing at any pace sets
  `stopHold` (the frozen stride, `holdSpeed`); it holds `CT.stopHoldTime` 1.7 s, then lets go and eases to a feet-together
  idle over `CT.stopEase` 0.35 s (`stopEaseT`, which also feeds `quickStop` so the loco blend eases out over that time).
  Any input, aiming, a stance change or leaving the ground ends the hold at once. `stopNoKneel` removed.
- **Turns (G25, G33):** `MotionDriver.stepCt` rewritten. Free movement moves along the FACING and the facing turns toward
  the stick at `CT.turnRate` 8.8 rad/s (504 deg/s, accel 300): no stationary pivot (stick held on the spot walks a tight
  circle), flick 180 and a run reversal are one smooth ~0.4 s turn (unit test: <= 0.45 s), no brake / plant / pivot
  state; the pace dips through a turn (`CT.turnDip` 0.55 at a full 180) and recovers. Only at the slowest speed
  (`MotionInput.slowest`, snapped gear 1) a stick more than 135 deg behind walks backwards at `CT.backSpeed` 0.5 m/s with
  the facing held (releases under 120 deg); faster speeds turn round. Aiming keeps strafe-locked, velocity along the
  stick. Enemies / cover keep the old driver path (`pivot` state stays for them).
- **Crouch / roll (G32):** `crouchTime` / `standTime` 0.22 s. A crouch press at a run (top speed, standing, >= 2.5 m/s)
  waits `CT.rollHold` 0.15 s (`PlayerController.crouchPend`): held it rolls (`traversal` reads `controller.rollHeld`;
  `CT.rollTime` 0.75 s, `CT.rollLength` 2.3 m, ends in a crouch run at the crouched top speed 2.6), released earlier it
  just crouches. A tap below the run crouches at once.
- **Co-op:** `PF.sprint` removed from the wire, `PROTOCOL_VERSION` 13 -> 14; `moveSpeedCap(mv, crouched, driven,
  grounded)` has no sprint argument; MoveState `g` is 1..5. Remotes pose from velocity / MoveState as before. The frozen
  stance is NOT sent: a remote's feet set down where they are and square up (prototype: revisit).

## Other changes
- Run-speed uses: a door bash needs standing, top speed, > 3.5 m/s; the gap hop needs > 3.5 m/s. The back-to-wall slide
  keeps the old gear caps (`WALL_GEAR_CAPS` in `wallController.ts`) until M3. The course drill verb `sprint` now means
  standing at speed 5.
- `GAIT_REF` (the gait clips' reference paces) re-mapped to five entries; `animGraph` is unchanged.
