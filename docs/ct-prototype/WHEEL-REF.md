# Selection wheel - reference (G181)

Michael sent a reference screenshot of the Blacklist-style selection wheel (2026-10-19, chat; the image itself is not
kept in the repo: reference-game art, G5 / G6). What it shows, described for the build:

## Layout
- A ring centred on screen over the dimmed game view, translucent teal panels with thin light borders; the game keeps
  running behind it (G181: no time slow).
- Outer ring: about 10 equal segments, each one item: an icon, and under it a count (`x3`) for gadgets or
  `loaded / reserve` ammo (`11/020`, `03/003`) for guns. Empty slots are blank dimmed segments.
- Items seen: the vision mode (a three-dot goggle icon labelled with the mode, at the top), throwables with counts,
  the pistol, a secondary / non-lethal launcher gun, a sticky camera, a noisemaker, the main gun at the bottom.
- The highlighted segment (the stick's direction) is brighter teal with a raised outline; its neighbours stay dim.
- Inner disc: a split centre toggle, one half "non-lethal" (open hand icon), the other "lethal" (blade icon), with a
  face button in the middle that switches them; the active half is lit and labelled.
- A two-line hint under the wheel in condensed caps: hold the button for the selection wheel, tap a face button to
  switch lethal / non-lethal.

## How it maps here
- Opens on hold (assumed LB hold, feel A1; the reference opens on a D-pad hold, but D-pad up / down is speed here, so
  this is an open question for Michael), right stick or mouse picks a segment, release selects. LB tap still
  switches weapon.
- Segments: the vision modes (night, thermal, electro; picking one sets what D-pad left toggles), the guns (pistol with
  the held jammer, rifle), the gadgets in the mission kit with counts.
- The lethal / non-lethal centre toggle is NOT built: the CT scheme already has both on the triggers (LT knockout, RT
  lethal, Michael "Yes, CT scheme"). Open question for Michael.
- Original art: our own icons and colour; condensed caps text uses the bundled Barlow Condensed (menu font).

## Second reference (PC, keyboard and mouse; Michael, 2026-10-19)
- Opens on a held Tab key on keyboard and mouse: use Tab hold here (mouse picks the segment, release selects).
- The vision segment at the top expands outward into a short stack of options above it (in the reference a second
  mode sits above the goggle mode with its own key hint). Here: night, thermal and electro stack in that top slot;
  the stack's other reference mode (a pulse-scan) is a non-CT system and is not built (G1).
- A label to the right of the wheel names the highlighted item and its mode in two lines (item name in white caps,
  mode in teal caps underneath).
- A hint box at the left in plain sentence case explains the key ("Press and hold [Tab] to access your gadgets ...").
- The centre lethal / non-lethal toggle shows its key hint inside the disc on keyboard ([B]); still not built here
  (open question, see above).
- Gun segments show the loaded count only (`13`, `31`, `03`); gadgets show `x3`.
