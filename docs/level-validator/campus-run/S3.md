## Schema limits met
- Door swings, stair rise / run / landing length, rails, beams, cameras, keypads and the shape of aisles inside a hall are not fields (H1, H3, H5, H7).
- The sheet has no catwalk, roof deck or changing-room class: `custom` and nearest-class choices.
- A hop across a 0.5 m gap has no kind: written as an `opening` width 0.5 (WARN by design).
- `route: loud` is ambiguous when every opening is one single door: used where the SPEC's loud route leaves the stealth route (stair south door, store hatch).
- One stair with two L1 doors is one `stair_core` space with two `fire_stair` links, which keeps the single stair visible to the redundancy check.
- `s3-walkway` has two ladders to the same neighbour: a V1 that counts distinct neighbours would call it a dead end (false positive).
- The `entry` landing shows one neighbour until the spine link from S2 is merged.
- Open-sky exterior ground around the buildings is nobody's space; H8 needs an exterior space or a note in the merged graph.
