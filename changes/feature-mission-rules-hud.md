# Mission rules: objective line and field menu
kind: minor
- Campaign missions no longer keep a mission list on screen.
- The objective line shows the current mission step, on the host and on the client. After Teale moves, the line changes to the moved step.
- Field Terminal > Objectives lists the rule first, then each step as done, current or to do.
- All of this ships dark behind the `missions` flag (`?missions=1`).
