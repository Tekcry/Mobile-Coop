# Old modes and maps removed
kind: minor
- Clean-up H: the old game modes are gone: Hunter (`clear`, `?mode=hunter`), Mission, Infiltration (its Play screen, briefing, mission picker, Missions row, mission list `config/missions.json`, stars on the results screen) and the PvP wording. `?legacy=1` and the Legacy menu row are gone too; the legacy-off game is the only game (the Loadout row is the read-only Kit screen; the old editable Loadout screen, profile badge and rewards panel went with it). The main menu is Co-op, Loadout, Settings, Feedback and the Test Chamber.
- Clean-up H, N22: Free Roam is removed (the main-menu row, the Free Roam screen and the co-op lobby's Free Roam choice). The Test Chamber covers free testing: its main-menu row, the benchmark and the lobby's Test Chamber choice already ran in the `test` mode, unchanged. The internal `sandbox` mode stays for the Kestrel editor's walk test and dev URLs only.
- Clean-up H, N23: the maps Warehouse, Proving Grounds and the five parked maps (Embassy, Mansion, Port, Refinery, Dust Depot) are deleted. An unknown map id now reads as Marlow Yard (was Proving Grounds). The listed maps are Kestrel only; Marlow Yard, Tallow Wharf, the Test Chamber, Kestrel, `seclab` and `courselab` stay.
- The co-op version is now 89 (`NetMode` lost `sandbox`, `clear` and `infiltration`; the `mission` field on `lobby` and `start` stays on the wire but is always empty), so an older build cannot join. The save format is unchanged (stage I changes it); the saved `missions` records and the Hunter / ghost challenges can no longer be earned.
- Tests: the e2e suites `e2e-clear`, `e2e-missions` and `e2e-ct-warehouse`, `e2e-parity` part 4, the `e2e-wall` flanker part, the Infiltration parts of `e2e-coop`, `e2e-offline`, `e2e-modes` and `e2e-menus`, and the `e2e-enemies` Perfectionist part are deleted; the other Warehouse and Proving Grounds boots run on the Test Chamber.
