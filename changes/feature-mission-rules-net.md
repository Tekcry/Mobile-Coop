# Mission rules: two-player campaign start and revives
kind: minor
- Campaign missions start only with exactly two players. With one player in the room the start is blocked, and the lobby says why.
- "Resume hosting" a campaign match waits in the lobby for the partner, then starts it on its own when they rejoin.
- Campaign missions give 2 revives at every difficulty. Syringes do not add more.
- All of this ships dark behind the `missions` flag (`?missions=1`).
